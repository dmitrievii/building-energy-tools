# Website

Public website layer for **Building Energy Tools**.

The website is intentionally separate from the interactive Climate Analyzer deployment. It provides project identity, discovery, methodology, teaching/research context and publication/legal information; interactive scientific tools may be hosted separately.

## Planned public sections

- Home
- Tools
- Teaching
- Research
- Documentation
- About
- Privacy / legal information

## Current publication content

Reusable public copy is maintained under `website/content/`:

- `about.md` — project/author identity and neutral academic affiliation
- `privacy.md` — deployment-aware privacy draft for the beta application

Project-wide identity rules are in:

```text
docs/PUBLICATION_POLICY.md
```

The mandatory pre-publication engineering gate is:

```text
website/PUBLICATION_CHECKLIST.md
```

## Publication status

The current Climate Analyzer candidate is `0.1.0-beta.1`, but the website/application must **not** be described as publication-cleared yet.

The publication checklist remains fail-closed until, among other things:

- the required public owner/address/contact information is intentionally approved;
- the final deployment-specific privacy notice is completed;
- actual browser cookies/storage/network requests are audited;
- accessibility/responsive review is performed;
- map/data attribution is verified in the deployed UI; and
- the software licensing decision is made before the project is described as open-source software.

Do not infer or substitute a TU Graz address for the independent project operator. The project's academic affiliation is biographical context, not institutional ownership of the independent website.
