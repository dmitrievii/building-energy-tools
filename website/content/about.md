# About Building Energy Tools

**Building Energy Tools** is an independent research and teaching project by **Ivan Dmitriev** focused on building physics, climate analysis and building performance.

The project develops small, auditable tools that make engineering data easier to explore in teaching, research and early design work. The first public application is **Climate Analyzer**, an interactive tool for EnergyPlus Weather (EPW) climate files.

## Project principles

- calculation methods and assumptions should be inspectable;
- source data should carry explicit provenance;
- scientific behavior should be protected by reference and regression tests;
- public interfaces should distinguish calculated results from heuristic design guidance;
- external datasets and institutional identities should not be presented with broader rights or endorsement than actually established.

## Current release

Climate Analyzer is being prepared as `0.1.0-beta.1`.

The beta designation means that the declared validation, security and runtime gates have been executed for the documented scope. It does not make the application a certification tool and does not replace project-specific engineering judgement or regulatory verification.
