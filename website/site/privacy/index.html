Publication information

Privacy

Draft status: the publication/privacy gate is not yet cleared for public promotion. This SITE-0.1 page summarizes the current technical facts and is not presented as a completed legal privacy notice.

Static website

The SITE-0.1 website is designed as plain HTML and CSS with no project-added analytics, advertising, external fonts or third-party runtime assets. The final hosting provider has not yet been selected or audited, so hosting logs and provider-side processing are not yet described here as final facts.

Climate Analyzer

Climate Analyzer is hosted separately on Streamlit Community Cloud. EPW files uploaded to the tool are sent to the application backend for analysis. The Building Energy Tools application does not intentionally persist those uploads in a project database.

Live deployment audits have observed provider-controlled session and analytics behavior in the Community Cloud wrapper. The project therefore does not claim that the current Streamlit deployment is privacy-cleared for Austrian/EU public promotion.

OpenStreetMap

The climate-station map is initialized only after a user explicitly selects Find climate. At that point, map tiles and supporting resources may be requested from third-party infrastructure. OpenStreetMap attribution is displayed in the map interface.

Current blocker

Final controller/disclosure contact information and the legal-basis/consent assessment for provider-controlled analytics and storage remain open. The maintained engineering draft is available in the project repository.
