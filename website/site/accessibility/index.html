Accessibility status

Accessibility

Accessibility is treated as an engineering quality gate, not as an unverified compliance label.

Static website foundation

SITE-0.1 uses semantic HTML, visible keyboard focus, a skip link, responsive layouts, system fonts, no essential animation and no JavaScript dependency for navigation.

Climate Analyzer audit

Automated desktop and mobile browser audits reported no horizontal overflow and no uncaught page errors. The application-owned file-uploader contrast issue found during the first live audit was corrected and verified in production.

Retained limitations

Two automated axe findings remain attributable to Streamlit-generated framework/platform markup. A manual keyboard, focus-order and 200% zoom review is still required before any claim of completed accessibility review.

No conformance claim: this status page is not a formal declaration of WCAG conformance.
