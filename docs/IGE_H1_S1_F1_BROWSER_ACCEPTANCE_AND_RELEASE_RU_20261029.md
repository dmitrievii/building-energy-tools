## Выполненная приёмка до переноса

Настоящий Chromium 153 открыл Streamlit, использующий исходный публичный `app.py`. Частный стенд `deployment/ige_h1_s1_f1_visual_harness.py` заменяет только получение данных на сохранённые оригинальные ответы. Поля, проверка допуска, расчётные методы, упаковка и HTTP-скачивание используются из приложения. Стенд не является публичной точкой запуска; в настройках Community Cloud остаётся `tools/climate_analyzer/app.py`.

Использованы раскрытые примеры Graz 2023 и исходный пакет NASA. Это проверка интеграции, не новая независимая оценка точности и не подгонка к наблюдениям.

Всего браузером скачаны **10 файлов**. В каждом EPW проверены 8 заголовков, 8760 строк по 35 полей и крайние временные метки. Проверены 8760 строк журнала F1 и согласованность T/p/q/RH/Td после чтения CSV. Во всех **80 файлах** исходного F1-контракта сохранены прежние SHA256: расчётные алгоритмы и старые результаты на этом этапе не менялись.

H1-стенд сохраняет оригинальную метку запроса `Graz Universitaet`, тогда как метаданные отображают `Graz Universität`. Компонент честно помечает сохранённый отчёт как предыдущую полную идентичность запроса; ID станции, год, исходные байты и количества часов при этом проверены. Это особенность воспроизведения сохранённого запроса, не разрешение подменять идентичность или метаданные в публичном получении источника.

## Материалы

В `deployment/audits/ige-h1-s1-f1-20261029/` сохранены снимки, `browser-acceptance.json`, независимая проверка скачанных файлов `download-verification.json` и хеши материалов. Снимки до переноса показывают стенд с оригинальными источниками, а не уже обновлённую публичную платформу.

Дополнительные снимки 11–12 фиксируют ограничение локальной среды: картографический iframe не загрузил содержимое; при мгновенном изменении размера дополнительного окна видна открытая боковая панель. Они **не подтверждают** визуальную работоспособность карты или её мобильную приёмку. Основные снимки форм F1 и Overview при 412 px не имеют переполнения страницы. Картографический компонент требуется отдельно проверить в публичном браузере после переноса; общий набор UI/download-проверок не подменяет эту проверку.

```bash
npm install --no-save playwright-core@1.55.0
python deployment/run_ige_h1_s1_f1_browser_acceptance.py \
  --chrome-path /usr/bin/google-chrome --out outputs/h1-s1-f1-visual
```

Для серверного Chromium без аппаратного GPU используются его программные библиотеки SwiftShader. Эти флаги относятся только к браузерному тесту; клиентам приложения не меняются настройки безопасности или графики. Первый локальный пакет браузера не мог быть получен с CDN; использован стандартный пакет Chromium из npm. Сервер и тест запускаются одним процессом-оркестратором, поскольку отдельные исполнительные сеансы не разделяют localhost.

## Граница допуска

Приёмка подтверждает работоспособность интерфейса, передачи данных, скачивания и численную воспроизводимость в указанной конфигурации. Сохраняются отдельные статусы: условная физическая согласованность, отсутствие новой независимой квалификации точности и ограниченный исследовательский режим эксплуатации. B4, P2 и R1 не повышаются в статусе. Глобальные исследования не выполнялись.

После переноса требуется отдельно наблюдать обновлённую публичную страницу Streamlit. Этот документ не выдаёт локальный стенд или GitHub Actions за проверку фактического Community Cloud deployment.
