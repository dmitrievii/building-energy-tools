# IGE P8.3B — проверка источника и пространственной устойчивости направления ветра

**Предрегистрация:** 2026-10-14. **Статус:** исследовательский эксперимент до получения численных результатов. Ветка: `research/ige-p8-3b-wind-qc-20261014`, создана от завершённого P8.3A, `main` и принятый P8.2F не изменяются.

## Мотивация

P8.3A (2021; ABO, BER, PAY; 26 280 часов) обнаружил: скалярный IDW даёт MAE скорости 0.640 м/с; векторный IDW улучшает точность направления на *одинаковых часах* 48.60→41.14° против ближайшей станции, но разрешает направление лишь примерно на 74% фактически нештилевых часов. Векторная скорость не предназначена для замены скалярной EPW Wind Speed. Требуется научное исследование надёжности азимутов и источника, не подбор численных параметров по исследованному 2021 году.

## Данные и исходное QC

- Исходные `ogd-smn_<station>_h_historical_2020-2029.csv` SwissMetNet; `fkl010h0` — hourly mean *scalar* wind speed (м/с), `dkl010h0` — hourly mean meteorological wind **FROM** (градусы). Номинальный UTC конец часа.
- **Важное ограничение:** MeteoSwiss согласно FAQ проверяет наземные измерения в течение пяти суток и исторические CSV являются пересмотренным источником, но открытые CSV могут **не содержать индивидуального QC-кода у каждого значения**. Нельзя обозначать отсутствие кода как `QC=passed`. Исследование регистрирует наличие колонок QC и принципиально не приписывает неизвестным кодам значение `accepted`. При отсутствии индивидуальных флагов статус `NO_EXPLICIT_PER_RECORD_QC_IN_HOURLY_CSV`; никакой искусственной имитации QC.
- Пустые значения скорости/направления исключаются. При скорости менее 0.5 м/с направление считается физически неопределённым. Остальные проверки числовой физической допустимости переняты из P8.3A; оригинальный показатель поставщика не заменяется ни прокси, ни вымышленным измерением.
- Данные доноров берутся строго за тот же наблюдаемый год и час. Целевая станция полностью исключается из доноров/прогнозной информации; её измерения доступны только оценочной функции.
- Кандидаты те же: ближайшие 20 метаданных SwissMetNet к каждой целевой станции + исходный контрольный пул; четыре ближайших станции, прошедшие годовой фильтр ≥90% часов с пригодным ветром; индивидуальный час требует минимум двух доноров. **Не меняется** алгоритм выбора доноров P8.3A.
- **2021** — уже исследованный год (exploratory, не blind). **2022** — новый, не использованный ранее в ветровом пилоте временной проверочный год с тем же неизменным протоколом; географического удержания независимых станций нет, поэтому это **temporal confirmation**, не полноценная универсальная валидация.

## Сравниваемые направления (все без изменения скорости)

A — **P8.3A vector-direction:** ветер `FROM` преобразуется в скорость `u,v TO` каждого донора, вектор усредняется весами `1/d²`, направление определено только если модуль среднего вектора ≥0.5 м/с. Это неизменный вызов `interpolate()`.

B — **unit-circle direction:** из *каждого нештилевого* донора берётся единичный вектор направления `FROM` (без умножения на скорость); среднее `sin/cos` строится с теми же IDW-весами, перенормированными по доступным нештилевым донорам. Необходимы ≥2 таких донора и безразмерная длина результата `R_unit ≥ 0.20`. **Порог 0.20 установлен до просмотра результатов**, не оптимизируется по 2021/2022. Если неопределённо — нет подставленного азимута.

C — **nearest original:** наблюдаемое направление ближайшего доступного донора из того же часа.

Скалярная скорость `V = Σ w_i V_i` всегда вычисляется неизменной P8.3A функцией независимо от выбора алгоритма направления. Векторная и скалярная скорости имеют разную семантику и не отождествляются.

## Проверка численных результатов

- По каждой целевой станции, году, сезону, интервалу скорости объекта (0.5–2, 2–5, ≥5 м/с), и согласованности доноров (R=0–0.3, 0.3–0.6, 0.6–0.85, 0.85–1): количество исходных нештилевых часов, охват векторного / unit / ближайшего, **строго совпадающие часы всех трёх направлений**, круговая MAE каждого метода на одинаковых часах (0–180°), дополнительные unpaired MAE только как диагностические, отдельно скорость скалярного IDW MAE/bias.
- Никаких ретроспективных поправок порога R, количества доноров, выбора станции и направления после чтения исходных результатов. Низкий охват и большая ошибка являются реальным отрицательным выводом.
- У каждого часа исходные наблюдения используются только в памяти CI; в GitHub выводятся лишь агрегаты по станции/сезону/скорости/согласованности, метаданные, SHA-256 исходников и статусы QC. **Запрещена выгрузка почасовых наблюдений**.
- 16 тестов контрактов P8.3B, 16 оригинальных P8.3A тестов, CI расчёты за 2021/2022. `main` и P8.2F immutability обязательны.

## Научное решение после результатов

Сохранить простую модель скалярной скорости и рассмотреть направление с явно указанной неопределённостью. Даже если круговой unit-IDW лучше, он не утверждается для генерации EPW только по 2021/2022 и трём станциям. Следующие необходимые блоки: независимые станции/регионы, топография и экспозиция, ветровая роза, persistence/turning, оригинальные инструментальные QC при наличии. Прошедший GitHub CI сам по себе **не равен** научной пригодности для природной вентиляции или ветрового генератора будущего.
