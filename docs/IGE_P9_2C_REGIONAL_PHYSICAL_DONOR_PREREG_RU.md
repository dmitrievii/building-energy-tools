# P9.2C — физически обусловленный подбор погодных доноров и независимая проверка AT/DE/CH

**Проспективный протокол 18 октября 2026; зафиксирован до чтения наблюдений за 2025 год.**

Отдельная ветка `research/ige-p9-2c-physical-donor-holdout-20261018`, основанная на закрытом P9.2B коммите `3ee0d4c3`. Ни мир, ни дополнительная станция или год в этом этапе не проверяются. Цель — один конечный аудит, который не разрастается в серию экспериментов.

**P9.2C1 (physical donor qualification):** перед случайным выбором суточного ERA5-донора исключить кандидаты, физически не способные сохранить исходные `huss` и `GHI` при температурных `tas/tasmin/tasmax` и реальном почасовом давлении. Затем выбрать по заранее заданной P9.2B весовой функции и фиксированному seed. Проверить, можно ли одновременно соблюсти `huss`, `hurs` и `RH_h ≤ 100%`, применяя физическое ограниченное перераспределение `q_h` (не подгоняя относительно наблюдений). При доказанной математической невозможности закрытия RH под данным T/p выдавать явный статус, оставляя `huss` жесткой, не подменяя измерения и не объявляя ошибку исходной CMIP6. Известные 28 исходных суток P9.2B = **development set, не новый holdout**. Нельзя оптимизировать коэффициенты по известным результатам P9.2B.

**P9.2C2 (independent original observational holdout):** одна станция каждой страны: **AT Graz (GeoSphere ID 30)**, **DE Oberstdorf (DWD ID 03730)**, **CH Davos (SwissMetNet DAV)**; только 10–16 января и 10–16 июля **2025** года, два сезонных окна по 168 UTC часов, всего 1008 максимально возможных часовых наблюдений T. Независимые оригинальные наблюдения T и доступную нативно квалифицированную RH брать из официальных первичных архивов: AT `tl+tl_flag` / `rf+rf_flag` при существовании у провайдера, DE `TT_TU/RF_TU/QN_9`, CH `tre200h0/ure200h0` (если исходный архив фактически включает их). Нельзя заменять отсутствующие переменные догадками или ERA5. Если RH отсутствует или QC неизвестна — `SOURCE_BLOCKED/NOT_QC_QUALIFIED` только для RH; T можно оценить отдельно. DWD QN9=3 автоматически QC, но НЕ эквивалентен QN10. Для CH timestamp означает конец интервала: фиксировать две раздельные временные чувствительности (same-label и shift -1h), не выбирать по наблюдению лучший lag.

Контрольный `P9.2C` исторический downscaling использует **оригинальные ежедневные агрегаты ERA5-2025** в качестве conditional targets, независимо от измерений станций. Это *ретроспективный reanalysis-driven downscaling experiment*, НЕ истинная независимая модель прогноза CMIP6 будущего: дневные T/RH/осадки/GHI из той же ERA5, что baseline. Текущее P9.2B требует native LW; для 2025, если native ERA5 longwave не удостоверено, использовать только явно обозначенный исследовательский surrogate для внутренних вычислений, **не оценивать и не квалифицировать LW по станциям**. Сравнение в одинаковые исходно QC-допустимые часы против B0 uncorrected ERA5-2025 и P9.2A original-day donor from 2019/2020. Важное ограничение: даже хорошо выглядящая динамика `T/RH` не доказывает физическую согласованность облачности, дождя или longwave.

**Предварительно заданные выводы:** сохранить все блокировки, периоды и количество QC часов; MAE/RMSE/bias 2m T и RH; случаи, когда P9.2C хуже B0 или P9.2A; минимальная достоверность 96/168 ч для данного site-season-variable. Для 2025 по геометрии/орографии без дополнительной высотной корректировки expected T bias особенно заметна в Oberstdorf/Davos — не подгонять. Не объявлять small sample statistical proof. Точно сохранять названия, units, source SHA, часовые метки, исходные 12 weather fields.
