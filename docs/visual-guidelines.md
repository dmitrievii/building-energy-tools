# Visual Guidelines

## Design direction
Minimal, architectural, academic, clear, technical but approachable, light, calm, not dashboard-heavy, not corporate SaaS-heavy.

## Visual language
Thin lines, architectural diagrams, axonometric building sketches, sun path diagrams, muted teal / grey / warm background, large serif headline typography, clean sans-serif UI typography.

## Hero visual strategy
Use a hybrid approach: generated or custom image without embedded text plus HTML/SVG labels and callouts.

Avoid text embedded in raster images, excessive gradients, complex dashboards on the homepage, too many cards above the fold, and student-only positioning.
