# IGE Climate Engine P8.1 — Independent Historical Spatial Reconstruction & Station Holdout Validation

**Статус:** станционный климатологический LOOCV принят как *research baseline*; полная историческая реконструкция по отдельным годам **ещё не выполнена**. `production_epw_ready=false`.

## Источник и независимость

Исходные данные: Tauernwetter Forschung (источник GeoSphere Austria, `klima-v2-1m`, homogenisierte Stationsreihen): https://tauernwetter.at/klimamittel/klimamittel_oesterreich.json ; DOI https://doi.org/10.5281/zenodo.21281130 ; CC BY 4.0, атрибуция GeoSphere Austria и Tauernwetter Forschung. Машинно-читаемый JSON имеет 258 станций; 189 используют строго климатическую норму **1991–2020**. Остальные 69 станций (различные укороченные периоды) исключены из основной выборки как предикторы и цели. Данные измерений обрабатывались внешним поставщиком и не являются прямыми нетронутыми минутными/часовыми показаниями приборов. Источник не получен из Meteonorm EPW. Неизвестно, входят ли те же измеренные станции в обучающие источники самого Meteonorm, поэтому *независимость IGE от Meteonorm как программного генератора* не тождественна полной независимости всех первичных станционных наблюдений.

Файлы исходного коммерческого Meteonorm не использованы в пространственной модели или LOOCV. Отдельная дескриптивная таблица `target_location_reconstructions.csv` сравнивает расчётные нормы 1991–2020 с агрегированными Meteonorm Contemporary; **их календарные нормы не доказаны одинаковыми**, сравнение не метрологическое.

Контроль воспроизводимости: `/source/klimamittel_oesterreich_from_indexed_text.json` — проверенная на JSON целостность реконструкция исходного библиотечного текстового представления, содержащая 258 станций. Исходные байты ответа с сайта отдельно не получены (ограничение доступа к сети контейнера), поэтому SHA-256 относится только к локальному нормализованному тексту, **не к оригинальному удалённому скачиванию**. Для окончательной исходной регистрации оригинальный файл необходимо скачать отдельно и сравнить распарсенное содержание и версии/даты обновления источника.

## Цель и защита от утечки

Для каждой из 189 станций целевые 12 месячных норм исключаются из входных данных. Выбираются до восьми других станций 1991–2020 по расстоянию на WGS84 (great-circle). Веса IDW `1/max(d_km,0.25)^2`. Два метода baseline: nearest station и IDW. Два варианта для температур: nearest/IDW с фиксированной априори высотной поправкой −0.0065 °C/м на разность `z_target−z_donor`. Использовано только 6 температурных/метеорологических полей: `tmittel`, `tmax`, `tmin`, `niederschlag_mm`, `luftfeuchte`, `wind_ms`. Поправка высоты **не применяется** к осадкам, ветру и RH. Метрики MAE, RMSE, смещение, p90 рассчитаны по 12 месяцам каждого holdout. Spatial buffer: 0, 10, 25, 50 км (все доноры ближе порога исключены). При расчёте нет анонимного захвата Meteonorm.

Допуск отсутствующих переменных: если измерения у станции неполные, соответствующее поле полностью исключается из её собственного holdout. Из 189 полный temp набор есть у всех; месячные осадки у 185. Распределение оценок по станциям, а не по 2268 псевдонезависимым месяцам, используется для station-cluster bootstrap.

## Результаты

Оценено **162 912** прогнозных комбинаций station × month × field × method × buffer. 189 станций с 12 месяцами среднемесячной температуры.

| Метод Tmean | MAE °C | RMSE °C | Bias °C |
|---|---:|---:|---:|
| Nearest raw | 1.617 | 2.586 | −0.087 |
| IDW raw | 1.322 | 2.100 | −0.036 |
| Nearest −6.5 K/km | 1.005 | 1.529 | +0.094 |
| IDW −6.5 K/km | **0.792** | **1.226** | +0.076 |

MAE Tmean для IDW с вертикальной поправкой: 0.712 °C (buffer 10 км), 0.772 °C (25 км), 0.829 °C (50 км). Неинтуитивное улучшение при 10 км не следует автоматически трактовать как «чем дальше доноры, тем лучше»: локальный станционный микроклимат/репрезентативность требуют проверки.

| Поле | MAE IDW без высоты | MAE IDW c высотой | Вывод |
|---|---:|---:|---|
| Tmean | 1.322 °C | 0.792 °C | поправка полезна |
| Tmax (средние месячные максимумы) | 1.861 °C | 0.704 °C | поправка особенно полезна |
| Tmin (средние месячные минимумы) | **1.114 °C** | 1.250 °C | единая поправка ухудшает среднюю ошибку |
| Месячные осадки | 11.451 мм/мес | неприменимо | требуется независимая орографическая модель |
| Средняя относительная влажность | 2.704 п.п. | неприменимо | дальнейшая физическая сверка |
| Скорость ветра | 0.804 м/с | неприменимо | без проверки направления и экспозиции |

Парный bootstrap станций (4000 повторений, фиксированный seed): средняя MAE-прибавка качества `IDW_raw MAE – IDW_lapse MAE` для Tmean = **+0.530 °C**, 95%-интервал **[+0.371;+0.707] °C**; Tmax = +1.157 [0.941;1.398] °C; Tmin = −0.136 [−0.288;+0.020] °C. Последний интервал содержит ноль: его нельзя интерпретировать как строго доказанное ухудшение.

Высотная стратификация Tmean IDW+lapse: ниже 500 м (67 станций) MAE 0.489 °C; 500–1500 м (106) 0.795 °C; выше 1500 м (16) 2.036 °C, смещение −1.825 °C. **Высокогорная переносимость неудовлетворительна.** Стандартная высотная поправка не заменяет рельефные барьеры, инверсии, экспозицию, снег/ледники и высотный режим склон/вершина/долина.

Целевые станционные LOOCV Tmean IDW+lapse: Graz Universität 0.528 °C MAE, Wien Hohe Warte 0.519 °C, Innsbruck Flughafen 0.700 °C, Innsbruck Universität 0.468 °C, Sonnblick 2.077 °C с холодным смещением около −2.075 °C.

Построены отдельные реконструкции **по точным координатам P8 Meteonorm** для Graz 332 м, Wien 200 м, Innsbruck 582 м, Sonnblick 3051 м. Эти значения *не* являются независимыми station holdouts, поскольку в качестве доноров для произвольной точки могут использоваться близлежащие станции. Для Sonnblick истинная исходная станция имеет высоту 3109 м; различие 58 м зарегистрировано. Для Tripoli (Peloponnese, Greece) отсутствуют корректные географические доноры, статус **BLOCKED**, австрийские данные не используются.

## Ограничения и P8.1 решение

1. Это **пространственный LOOCV климатических норм 1991–2020**, не ежегодное/суточное/часовое независимое восстановление 1995–2014 и не проверка событий.
2. Для первой независимой калибровки 8 станционных доноров, IDW и глобальный lapse хорошо работают для Tmean/Tmax в средней высоте, но не закрывают Tmin, высокогорье, осадки, солнце или ветер.
3. Подлинный P3/P5 исходный архив в этом запуске не сравнен построчно с новым алгоритмом. Этот P8.1 код является новым экспериментальным baseline, а не подтверждением, что исходная реализация P3 уже имеет ту же точность.
4. Необходимо отдельно выполнить calendar-year holdout исходных GeoSphere станционных рядов и holdout целых региональных кластеров. Условия RCP/SSP не относятся к этим результатам.
5. Нельзя присваивать `production_epw_ready=true` на основании LOOCV климатических норм.

**Решение:** `P8.1_MONTHLY_SPATIAL_HOLDOUT_PASS`; `P8.1_FULL_HISTORICAL_DAILY_VALIDATION_OPEN`; `P8.1_TRIPOLI_BLOCKED_PENDING_GREEK_OBSERVATIONS`.
