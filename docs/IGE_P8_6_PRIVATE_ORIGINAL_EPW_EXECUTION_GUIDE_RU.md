# IGE P8.6 — Локальный запуск проверки 57 лицензированных EPW

**Текущий статус:** в GitHub CI доступны только публичные исследовательские погодные файлы. Полная приватная проверка 57 оригинальных файлов остаётся **BLOCKED**, пока исходные байты не будут предоставлены в доверенной локальной среде. Не загружайте лицензионные Meteonorm почасовые данные в публичные GitHub Actions artifacts или репозиторий.

## Необходимые входные файлы

1. **Оригинальный baseline** `Graz-hour_contemporary_seed1.epw`, ожидаемый SHA256 `dad69174304c3a13cc095841c4cb9636bf99cc3a81502c553af862cd06677`.
2. **Оригинальные 28 P7C.4** `*_P7C4_HOURLY_ENSEMBLE_RESEARCH_ONLY.epw` — из неизменённого старого архива. Ожидаемые имена и SHA прописаны в `research/ige_cmip6/results/p7c4_28_hourly_model_summary.csv`. Можно передать путь к папке **или** ZIP (подпапка внутри ZIP допускается).
3. **Последние 28 P7C.5B** `*_P7C5B_SOLAR_ILLUMINANCE_RESEARCH_ONLY.epw` — из исправленного фотометрического архива. Ожидаемые исходные/новые SHA прописаны в `research/ige_cmip6/results/p7c5b_photometric_28_summary.csv`. Можно передать папку **или** ZIP.

Именно эти три группы дают **57 оригинальных EPW**. Не использовать 4 заблокированных IPSL как замену и не принимать старые P7C.4 за последние P7C.5B.

## Команда в корне репозитория (Windows PowerShell)

```powershell
python research/ige_cmip6/p8_6_private_crossfield_qualification.py `
  --baseline "D:\IGE\private\Graz-hour_contemporary_seed1.epw" `
  --p7c4-original-dir-or-zip "D:\IGE\private\P7C4_original_28.zip" `
  --p7c5b-corrected-dir-or-zip "D:\IGE\private\P7C5B_corrected_28.zip" `
  --out "D:\IGE\private\p8_6_results"
```

**Важно:** выполнить из корня `building-energy-tools`, чтобы относительные ссылки на исходные CSV были корректны; Python должен иметь доступ к `numpy` и другим зависимостям проекта. Скрипт читает оригиналы в памяти, проверяет SHA каждого файла, 8760×35, 365 суток/часовые метки, допустимые изменения 9 климатических полей P7C.4 и только полей освещённости 16–18 P7C.5B, физическую согласованность психрометрии, солнечной геометрии, прямой/рассеянной радиации, освещённости, sky IR, облачности, ветра и осадков, месячные GCM-множители и погодные экстремумы.

**Результат:** `p8_6_original_28_plus_28_crossfield_aggregates.json` — только сводки по оригинальным файлам, контрольные суммы, физические флаги и статистика; никаких почасовых коммерческих данных в отчёте. `critical_crossfield_physical_pass_all_28` может быть `false`; значит физическая проверка обнаружила ошибки, даже когда SHA совпали. `production_epw_ready=false` остаётся обязательным до независимой погодной квалификации.

## Реальный EnergyPlus на 28 последних EPW

Уже существует локальная программа `research/ige_cmip6/p7c5b_private_energyplus_benchmark.py`: она выполняет **29 годовых испытаний** (исходный Meteonorm + 28 последних P7C.5B) на установленном EnergyPlus 26.2.0, с проверкой SHA и реальных выходных SQL.

После P8.6 source/QC шага запустить отдельно:

```powershell
python research/ige_cmip6/p7c5b_private_energyplus_benchmark.py `
  --baseline "D:\IGE\private\Graz-hour_contemporary_seed1.epw" `
  --epw-dir "D:\IGE\private\P7C5B_corrected_28" `
  --energyplus "C:\EnergyPlusV26-2-0\energyplus.exe" `
  --official-idf "D:\IGE\private\official_1ZoneUncontrolled.idf" `
  --out "D:\IGE\private\p8_6_energyplus"
```

Для этого скрипта **нужна распакованная папка** с 28 исправленными EPW **и** оригинальным `p7c5b_photometric_science_audit.json`; ZIP он пока не принимает. Путь EnergyPlus/IDF выше лишь пример, должен соответствовать фактической установке и точной версии 26.2.0.

**Критический нюанс:** EnergyPlus-прогоны тестовой одномерной зоны не доказывают физическую точность климата, а проверяют техническую пригодность EPW и чувствительность расчётов. Не трактовать эти 29 запусков как независимое подтверждение климатических распределений, экспозиции ветра или освещённости.

## Прозрачность публичного CI

В GitHub Actions P8.6 **не загружаются** лицензированные оригиналы. Единственный реальный файл CI — публичный архивный исследовательский P7B.5 с синтетической термодинамикой и аналоговыми ветровыми направлениями. Его самостоятельный физический smoke-тест маркируется `scientific_original_57_file_gate_pass=false` независимо от результата проверки.

Нет (57/57) оригинальных EPW → нет претензии на финальную квалификацию P8.6.
