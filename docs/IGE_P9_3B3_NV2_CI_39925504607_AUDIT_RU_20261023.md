Graz two-column P2 blend: **0.2490** hPa зимой и **0.5408** hPa летом. Он не превосходит лучший из двух фиксированных single donors ни в одном дне. D2 лучше D1 зимой, D1 лучше D2 летом; выбирать donor по сезону из этих раскрытых residuals нельзя. В DE различия методов малы. В CH зимой лучше фиксированный Γ, летом isothermal P1. Статистическое общее превосходство P2 здесь не установлено.

### Почему Graz D1 не различает P1_iso/P2

Barometer 378.8 m находится лишь на 6.2407 m выше model surface 372.5593 m и **во всех 50 source nodes остаётся внутри самого нижнего слоя**. В выбранном kernel T/q внутри слоя постоянны, поэтому:

\[
\ln p_* = \ln p_s-\frac{\Phi_*-\Phi_s}{R_dT_v}
\]

одинаково для P1_iso и P2. Наблюдаемая максимальная разница 8.73·10⁻¹¹ Pa — вычислительная погрешность. Это математическая эквивалентность двух реализаций при данном representation, а не дополнительная проверка качества вертикального профиля P2.

| Berlin T/RH / D1 | **+0.50594 m** | Номинальный допуск проходит, 2 m buffer sensitivity не проходит |
| Davos T/RH / D1 | +387.11084 m | Номинальный и 2 m lower-bound checks проходят; hourly top также подтверждён |

Для совместного T/p/q state Graz остаётся геометрически пригоден **D2**, выбранный до scores, независимо от сравнительного MAE. D1 можно использовать для отдельного barometer diagnostic, но нельзя подставить как источник T/RH на 368.7 m. В Berlin малый запас особенно ограничивает интерпретацию при несертифицированном MSL→geopotential datum mapping. Buffer=2 m — design sensitivity, не установленная погрешность геодезии.

Разнесение barometer и T/RH по высоте/координатам сохраняется в результатах. Восстановленное p на уровне T/RH не имеет прямой barometer truth. q, вычисленная позднее из station T/RH и reconstructed p, не будет независимым измерением q.

Оба Graz donors находятся с одной стороны станции: fixed weights ≈0.60349/0.39651, first moment norm ≈**30.46 km**, target вне их convex hull. Два значения не определяют полный 2D pressure gradient. Donor spread не calibrated CI. При расширении профиля с уровней 124–137 до 109–137 single-donor pressures в двух контролях не изменились; AT blend изменился максимум на **0.0014098 hPa**. Это зарегистрированная sensitivity только двух часов, не верхняя граница годовой ошибки. В общем случае blended anchor зависит от выбранной верхней границы; между границами слоёв:

\[
\frac{\partial\ln p_{blend}}{\partial\Phi_a}
=\frac{1}{R_d\widetilde T_v(\Phi_a)}
-\sum_j\frac{w_j}{R_dT_{v,j}(\Phi_a)}.
\]

Здесь \(\widetilde T_v\) строится из смешанных T/q. Равенство нулю не обеспечено для разных колонок; blend остаётся sensitivity model, а не автоматически более точным методом.

## 4. Регрессия и provenance

Сравнены **400 G0 source-node pressure values** с исходным Work artifact 39757573033. 391 совпали побитно; 9 отличаются максимум на **1.4552·10⁻¹¹ Pa**. Геометрический отказ AT и DE/CH results воспроизвелись до численной точности. Предыдущие отчёты и JSON не перезаписывались.

Из 1660 общих source objects **1655 побайтно идентичны**. Все потреблённые T/q/z/lnsp data chunks и все шесть pressure products имеют прежние SHA. Изменились bytes пяти metadata objects: AT provider metadata, AT/DE WMDR XML, T и q ARCO `.zmetadata`. Датированные поля приборов совпали после исключения hashes; текущие field semantics/hybrid coefficients прошли guard. Предыдущие полные `.zmetadata`/XML bodies не экспортировались в Work artifact, поэтому причина SHA drift **не установлена**. Нельзя выдавать новые metadata за побайтную копию старых или объяснять различие неподтверждённым обновлением временной оси. Следующим запускам следует сохранять полные небольшие metadata snapshots вместе с hashes.

Original GRIB z/lnsp controls: 4/4 exact-after-float32, по 410 240 коэффициентов, совпадают с прежними source controls. Проверка не заявляет original-GRIB byte identity для всех T/q chunks или всех 50 часов. NASA semantics, saturation/ice conventions и condensate loading этим pressure-пилотом не квалифицированы.
