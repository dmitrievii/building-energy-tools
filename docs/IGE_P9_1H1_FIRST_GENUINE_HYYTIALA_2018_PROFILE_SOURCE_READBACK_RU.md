**17.10.2026. Статус: исследовательский source readback выполнен; окончательная квалификация QC не пройдена.** Ветка `research/ige-p9-1h-near-surface-inversion-20261017`. `main` не изменён.

## 1. Оригинальные источники

University of Helsinki / SMEAR II, настоящий API SmartSMEAR `https://smear-backend.2.rahtiapp.fi/search/timeseries`, открытая спецификация OpenAPI 1.1.1.

- `HYY_META.T42` — температура воздуха на 4,2 м, Pt100 в вентилируемом радиационном экране.
- `HYY_META.T672` — температура воздуха на 67,2 м, Pt100 в вентилируемом радиационном экране.
- Метаданные датчиков непосредственно получены у поставщика. Единицы — °C, таблица `HYY_META`, права чтения — public.
- Исходные метки `samptime` заданы **местным стандартным временем UTC+02:00 без перехода на летнее время**, согласно документации SMEAR. Они переведены в UTC; синхронизация выполнена по точным совпадающим минутам.
- API вернул `aggregation=NONE`, `recordCount=10080` по каждому датчику и семидневному периоду. Искусственное заполнение пропусков и использование ERA5 отсутствуют.
- Исходные ответы API не публикуются, но их SHA-256 зафиксированы. Агрегаты и проверка: [GitHub Actions #39061254895](https://github.com/dmitrievii/building-energy-tools/actions/runs/39061254895), артефакт `12111526997`; окончательный повтор на ветке — [#39061488587](https://github.com/dmitrievii/building-energy-tools/actions/runs/39061488587), SUCCESS.

**Ограничение:** сервис предоставил температурные ряды, но нативная схема QC и датчиковые флаги ещё не независимо подтверждены. Отсутствие пропуска не доказывает строгую проверку наблюдения. Результаты ниже предварительные, пригодные для аудита источника и постановки гипотез, но не для квалификации предсказательной модели.

## 2. Зарегистрированные периоды и эксперимент

Периоды разработки фиксированы до просмотра измерений: **10–16 января** и **10–16 июля 2018** включительно. Независимые наблюдения 2021 года не запрашивались.

Обозначения: `ΔT=T_67.2−T_4.2`; `Δz=63 м`; положительная температурная инверсия для предварительной классификации — `ΔT>0,10K`. Часовая разность вычисляется при наличии минимум **45 реально зарегистрированных синхронных минутных пар**. Сравнение градиента потенциальной температуры с физической температурной инверсией недопустимо.

Заметное летнее повышение температуры между 4,2 и 67,2 м может отражать стратификацию и радиационный обмен **внутри лесного полога и над лесом**. Оно не доказывает эффективность диагностики холодновоздушных озёр в горных долинах. Два семидневных периода не характеризуют весь климат региона. В работе пока нет сопоставления с ERA5 и оценки MAE модели.
