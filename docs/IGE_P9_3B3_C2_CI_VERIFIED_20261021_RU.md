### Причина Davos подтверждена отдельным расчётом

Для target 13.02.2021 заново прочитаны те же ERA5-derived source окна CH 2019 и 2021; canonical hourly hashes совпали с CI. Сами source T/q/RH согласованы по построению. C2 заранее выбрал общий wet/month eligible донор **04.02.2019**, без выбора по поправкам или station errors.

После аффинного масштабирования до Tmin/Tmax target:

\[
\bar T_{source}=259.0708333333\;K,\qquad
\bar T^0_{donor}=256.3461904762\;K.
\]

Независимо от оптимизатора C2 составлены границы \(l_i=\max(T_{min},T_i^0-2)\), \(u_i=\min(T_{max},T_i^0+2)\), с фиксированными extrema indices. Уже pointwise box даёт:

\[
\bar T\le {1\over24}\sum_i u_i=257.9980952381\;K
<259.0708333333\;K.
\]

Независимые LP минимального/максимального среднего с тем же slope bound подтвердили [254.7733333333, 257.9980952381] K. Разрыв до source mean составляет **1.0727380952 K**. Следовательно, поправки q/RH при этих жёстких T-условиях не помогут. Это ограничение одного frozen donor T-prior, **не** физическая невозможность погоды Davos и не доказательство несовместимости исходных daily diagnostics. B3 остаётся UNRESOLVED по своему ограниченному поиску; его статус не заменён глобальным infeasible.

**C2 можно зафиксировать как проверенную условную research-реализацию физической проекции и прозрачного учёта source-поправок.** Следующие научные задачи — source-verified вертикальный pressure reference и математически допустимая модель выбора/геометрии T-донора; затем сравнение активных мягких режимов на действительно новом AT/DE/CH блоке после фиксации правил. Изменять текущие веса, donor policy или ширину ±2 K по этому раскрытому провалу нельзя без отдельного обоснования и нового протокола. Глобальная валидация остаётся отложенной до публикации.

В review commit меняются только новый audit JSON, этот отчёт и перевод C2 workflow на **workflow_dispatch only**, предусмотренный initial_CI протоколом. Python алгоритм, физические коэффициенты, source protocol и старые результаты остаются байтово неизменными; main и merge не затрагиваются. Новый длительный CI для отчётных файлов не запускается.
