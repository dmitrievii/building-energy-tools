# IGE P8.3A — независимая пространственная реконструкция вектора ветра

**Статус:** новый исследовательский этап; методика до появления результатов, 2026-10-14. **Ветка:** `research/ige-p8-3a-spatial-wind-20261014`, созданная от сохранённого P8.2F baseline. `main` не изменён.

## Цель

Начать новый климатический модуль после принятия P8.2F, не продолжая подгонку T/e/RH. Проверить на реальных оригинальных почасовых наблюдениях SwissMetNet, возможна ли пространственная реконструкция **скорости и направления ветра** для целевой станции из соседних доноров. В отличие от температуры и e, направление — круговая переменная; нельзя усреднять 359° и 1° как 180°.

## Источники и контроль разделения данных

- SwissMetNet, исходный файл `ogd-smn_<site>_h_historical_2020-2029.csv` за **2021 год** и официальный `ogd-smn_meta_stations.csv`. Исходное UTC время записи относится к указанной часовóй метке источника, без произвольного сдвига.
- `fkl010h0`: средняя скалярная скорость ветра, **м/с**; `dkl010h0`: среднее метеорологическое направление ветра **«откуда»**, градусы. Исходные коды/единицы должны быть проверены по официальному метаданному справочнику перед публикационной квалификацией.
- Цели заранее: ABO, BER, PAY, 2021. Они исключаются из доноров по идентификатору; реальные показания целевой станции читаются **только для оценки результатов**.
- Из официальных метаданных берём 20 ближайших кандидатов для каждой цели плюс неизменный контрольный пул из 12 станций. Каждый донор проходит порог ≥90% пригодных часов ветра за год: измеренная скорость и направление при ≥0,5 м/с; при штиле направление не обязательно. Четыре ближайших пригодных донора выбираются по расстоянию, независимо от наблюдений целевой станции.
- Для каждого часа фактический состав пригодных доноров может сократиться до двух; если менее двух, час не рассчитывается. Возвращаем диагностический пропуск, не подставляем фиктивное направление.

## Два физических способа для проверки

Вектор компоненты ветра **«куда»**, если азимут «откуда» — θ по часовой стрелке от Севера:

\[
 u=-V\sin\theta,\qquad v=-V\cos\theta.
\]

Арифметически интерполируем только компоненты `u, v` с теми же IDW-весами, что приняты для пространственного исследования T/e:

\[
\bar u=\sum_i w_i u_i,\quad \bar v=\sum_i w_i v_i,
\quad V_{\mathrm{vector}}=\sqrt{\bar u^2+\bar v^2},
\quad \theta_{\mathrm{from}}=\operatorname{atan2}(-\bar u,-\bar v)\pmod {360^\circ}.
\]

Второй исследуемый baseline для **скалярной скорости**: \(V_{\mathrm{scalar}}=\sum_i w_i V_i\). Он не равен модулю среднего вектора при расхождении направлений. Третий контроль — одна ближайшая станция. Не выбирать вариант по результатам 2021 года; сначала сопоставить физический смысл.

Для итоговой скорости Wind Speed EPW в дальнейшем нельзя автоматически выбрать векторную скорость только потому, что векторное направление рассчитано физически; синхронный скалярный часовой wind-speed и векторный модуль отличаются даже на одной метеостанции.

## Независимые метрики и критерии отказа

- Почасовая MAE, RMSE, bias скорости (м/с) для скалярного IDW, векторного IDW и ближайшего донора на **одинаковых** проверенных часах.
- Средняя абсолютная круговая ошибка направления (0–180°) для нештилевых часов, при выдаче допустимого векторного направления; обязательно публиковать **охват направления** и долю часов, в которых вектор обнулился из-за противонаправленных ветров. Ошибку не скрывать удалением трудных часов.
- Проверка физики: \(V_{vector}\le V_{scalar}\), круговой переход 359°↔1°, правило штиля, валидность исходных полей.
- Минимум 80% пригодных целевых часов на каждую станцию, иначе fail-closed. Нет искусственного восстановления отсутствующих измерений, часов, штиля или направления.
- Выход — только CSV агрегатов по целям, метаданные станций/дистанций, SHA-256 оригинальных файлов, программный статус. Оригинальные почасовые записи в публичные артефакты не включать.

## Научные ограничения

- Этот этап использует **наблюдения доноров тех же дат и часов**. Это пространственный hindcast, **не генератор будущего ветра**.
- Измеренная скорость и направление SwissMetNet могут быть инструментально/алгоритмически усреднены разными способами; без исходных метаданных нельзя утверждать, что преобразование к единому вектору строго воспроизводит инструментальное измерение.
- Это **первый трёхточечный пилот**, а не универсальная валидация для сложного рельефа, высотных поправок или городской застройки.
- Результаты не создают 35-колоночный EPW и не подтверждают натуральную вентиляцию, аэродинамическую пригодность фасадов или ветровую циркуляцию будущего климата.
- Последующий этап требует расширения независимых станций/регионов и проверки типа измерений, ветровой розы, штилей, эпизодов, разницы высот и времени наблюдений.

## Соседние, но отдельные исследования

P7B.5 — условный генератор направления ветра для синтетических GCM-погод. P8.3A — пространственная интерполяция реально наблюдаемого одновременно ветра. Не выдавать результаты одной методики за доказательство работоспособности другой.
