5. Сохранить original packet/receipts/ошибки в артефакте и git **до таблиц ошибок**.
6. Выполнить прежний scorer; сохранить все72 случая, пустые пары и source blocks.
7. Отдельно воспроизвести scorer без сети; сверить paired arithmetic через fsum и явную
   группировку. Эта QA-проверка не является другим estimator или независимым источником погоды.

## Австрийское лето и пределы независимости

Уже до controls все2688 летних donor T у16 AT доноров имели finite значения с native QC0;
1008 летних R1 прогнозов отсутствовали. Теперь у всех6 AT target products в летнем окне
тоже обнаружено по168 QC0 строк — **1008 QC0, 0 QC10**. Это не пропавший HTTP response.
Значения не переименованы вQC10 и не включены в первичные метрики; шесть случаев остались в журнале.

AT QC10 означает опубликованный автоматически проверенный продукт с неизвестной оригинальностью;
не подтверждается неизменённая sensor T. DE — TT_10 HH:00/QN3; CH — published-h без row QC
и прежний модельный six-node surrogate. Номинальная геометрия2м и временные определения не
сертифицируют sensor filters, общий vertical datum, spatial-QC независимость поставщика или
неучастие станций в ассимиляции ERA5. Поэтому это заранее зарегистрированное station-held-out
сравнение объявленных продуктов с ограниченной независимостью, без региональной или мировой квалификации.

Весь полученный многолетний/многопараметрический raw container теперь раскрыт, включая
неиспользованные годы/поля. Эти bytes больше не могут называться свежим holdout.
Старые AT2018 и IV1 2022 controls не открывались. Обе даты2013/2014 остаются регрессиями.
