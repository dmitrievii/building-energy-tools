## План до открытия контролей

Этот раздел публикуется до любых новых target station/QC requests. M4 исполняет уже
зарегистрированную контрольную фазу. Научный M2-код, scorer, наблюдаемые величины,
операторы времени, QC, 18 целей, фиксированные доноры, даты, метрики и критерии неизменны.
M3-предикторы не загружаются повторно. main, merge, deployment и default не затрагиваются.

1. Повторить без сети научные154 проверки и расчёт прогнозов из опубликованных исходников.
2. Выполнить13 новых синтетических проверок executor/paired arithmetic.
3. Проверить точный опубликованный prediction gate и записать одноразовый control marker.
4. Запросить только18 control assets из M2 source inventory, прошедшие sealed source admission.
5. Сохранить original packet/receipts/ошибки в артефакте и git **до таблиц ошибок**.
6. Выполнить прежний scorer; сохранить все72 случая, пустые пары и source blocks.
7. Отдельно воспроизвести scorer без сети; сверить paired arithmetic через fsum и явную
   группировку. Эта QA-проверка не является другим estimator или независимым источником погоды.
8. Опубликовать оригинальные scores/pairs/replay и проверить скачанные ZIP/SHA256 отдельно.

Первичные QC остаются AT10, DE TT_10 QN3 и отдельная CH published-h страта без row QC.
AT source-QC0 не переименовывается в10; target-QC0 также не допускается.
AT QC10 оценивает опубликованный продукт с неизвестной оригинальностью, не неизменённый датчик.
Модель/наблюдение CH сравниваются как шесть номинальных узлов с прежним модельным оператором
5/12 previous +7/12 current; endpoint-инверсия и t-архивы не входят в M4.

Все18 целей имеют хотя бы одну неделю с≥160 готовыми парными прогнозами, поэтому source gate
разрешает их архивы. Однако у AT все шесть summer cases содержат0 R1 forecast hours.
Их отсутствие не исправляется. Требование24/24 допущенных случаев для country pilot uniform
benefit уже недостижимо для AT. У остальных стран forecast coverage24/24; фактический допуск
определится после target-QC и парного сопоставления.

Первичная метрика — MAE_R1−MAE_B0 на **одних и тех же часах**, отдельно по station/season/country/QC.
Также RMSE, bias, centred RMSE, B0 на всех пригодных reference hours и coverage.
Случаи<160 пар остаются описательными. Для ограниченного uniform-benefit пилота:
24/24 случая≥160 пар, country paired deltaMAE<0 и у каждой6 станций deltaMAE≤0.
Это observed-score правило с нулевой границей, не significance/equivalence/no-harm confidence.

чувствительность; объединённый AT/DE/CH победитель не выбирается.
