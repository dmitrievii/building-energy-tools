# SEO Guidelines

## URL structure
English MVP: `/en/...`
Future German version: `/de/...`

## Metadata required for each page
- SEO title
- Meta description
- Canonical URL
- Open Graph title
- Open Graph description
- H1
- Structured heading hierarchy

## Multilingual SEO later
Each translated page must have self-canonical, hreflang alternates, translated SEO title, translated meta description, and locale-specific route.
