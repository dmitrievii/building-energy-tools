Поиск по файлам проекта, беседы, доступной Library и рабочей файловой системе не нашёл оригинальный `Graz-hour_contemporary_seed1.epw` и ZIP с 28 P7C.4 / 28 P7C.5B лицензированными EPW. Из доступных отчётов P8.5 имеются только индивидуальные SHA-256 и агрегаты. **0 из 57** приватных оригинальных файлов действительно перечитано на данном этапе.

Следовательно, проверки реальных 28 сценариев по физике влажности, облачности, radiometric/photometric coherence, ветровым часам и экстремальным событиям, а также **29 нативных EnergyPlus-расчётов** на приватных Meteonorm EPW остаются **NOT EXECUTED**. Они не могут быть признаны успешными по зелёному CI тестового анализатора.

## Выполнение на оригинальных файлах

[Инструкция с командами Windows PowerShell](IGE_P8_6_PRIVATE_ORIGINAL_EPW_EXECUTION_GUIDE_RU.md) описывает запуск:

```powershell
python research/ige_cmip6/p8_6_private_crossfield_qualification.py `
  --baseline "D:\IGE\private\Graz-hour_contemporary_seed1.epw" `
  --p7c4-original-dir-or-zip "D:\IGE\private\P7C4_original_28.zip" `
  --p7c5b-corrected-dir-or-zip "D:\IGE\private\P7C5B_corrected_28.zip" `
  --out "D:\IGE\private\p8_6_results"
```

Код проверяет оригинальные байты **только локально**, а отчёт `p8_6_original_28_plus_28_crossfield_aggregates.json` не содержит исходных почасовых значений. Для EnergyPlus уже есть `p7c5b_private_energyplus_benchmark.py`: запуск 29 погодных файлов на EnergyPlus 26.2.0. Эти расчёты следует выполнять отдельно после исходного SHA/физического скрининга.

**Решение:** методика P8.6 реализована и контрактно проверена, **но окончательное закрытие научной квалификации всех 28 оригинальных EPW невозможно без трёх групп исходных файлов**. Не мержить `main` и не менять статус `production_epw_ready=false`.
