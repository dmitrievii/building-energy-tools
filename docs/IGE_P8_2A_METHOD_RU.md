# IGE Climate Engine P8.2A — Historical Humidity Spatial Reconstruction

## Научная задача

После завершения P8.1A–F по температуре проверить пространственную интерполяцию **водяного пара** как фундаментальной влажностной переменной. Нельзя просто переносить относительную влажность по высоте: RH зависит от температуры, а e характеризует массу водяного пара косвенно через парциальное давление. Переход к EPW и будущему климату рассматривается отдельно.

## Независимые наблюдения

GeoSphere Austria klima-v2-1m; проверка единиц измерения и индивидуального QC для `tl_mittel` (°C), `dampf_mittel` (hPa), `rf_mittel` (%), `absf_mittel` (g/m³), `p` (hPa). Исторические значения 1991–2010 используются для обучения коэффициентов, целевые станции исключены из обучения и донорского набора, 2011–2020 используется только как withheld truth для целевой станции. Данные тех же лет с *других* станций допускаются в spatial hindcast. Флаги, отсутствующие данные и неподдерживаемые значения не заполняются автоматически.

## Проверяемые методы

Для влагосодержания сравниваются арифметическая IDW интерполяция e; геометрическая IDW e; геометрическая с постоянным логарифмическим высотным градиентом −1/2000 м⁻¹; геометрическая IDW с региональным высотным градиентом логарифма e, полученным исключительно на 1991–2010. Региональный градиент предварительно освобождается от линейных lat/lon эффектов и регуляризуется априорным значением −1/2100 м⁻¹. Ограничения градиента: [−0.0025,+0.0005] м⁻¹. Расстояния IDW — горизонтальные, восемь доноров, exponent 2, maximum radius 350 км. Сравнение при географических буферах 0 и 50 км.

Для RH сравниваются прямая IDW среднемесячной измеренной RH и вторичная диагностика `100*e_pred/es(T_pred)`. Здесь `T_pred` рассчитана заранее зафиксированным P8.1B температурным градиентом по другим метеостанциям (не температуре target). **Нельзя требовать совпадения** со среднемесячной измеренной RH: `mean[e/es(T)] ≠ mean[e]/es(mean[T])`. Такие расхождения не являются сами по себе нарушением физических законов. Значения не ограничиваются принудительно диапазоном 0–100%, а заносятся в диагностику. Аналогично проверяется абсолютная влажность через `216.7 * e[hPa]/T[K]` против оригинального `absf_mittel`, с явной оговоркой о месячном усреднении.

## Метрики и гейты

Для e: MAE/RMSE/bias/P90 в hPa, высотные диапазоны, помесячные и постанционные ошибки, paired station-level bootstrap CI. Для RH: отдельно MAE в процентных пунктах. Для абсолютной влажности: MAE в g/m³. Когорты могут различаться и это фиксируется в отчете; сравнения методов **внутри одной переменной** проводятся на совпадающих точках. Не проводить подгонку метода по test-year. Сложную модель включать в IGE только при устойчивом улучшении на независимой географической выборке; настоящий этап — австрийская проверка, а не готовый алгоритм глобального применения.
