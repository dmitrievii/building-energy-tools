# IGE: почасовая проверка пространственной интерполяции

Дата решения: 7 ноября 2026 года.
Статус: согласованные правила построения исследовательской выборки и сравнения методов.

## 1. Единица испытания и неполные ряды

Единица проверки — «контрольная площадка × временная метка × величина».
Полный календарный год не является условием включения площадки или её наблюдений
в эксперименты по пространственной интерполяции. Используются все доступные часы,
для которых есть контрольное значение и достаточно независимых донорских данных
для конкретного метода. Можно исследовать фрагменты года, сезона или суток.

Условие наличия данных применяется отдельно к каждой величине и её физически
необходимым входам. Отсутствие давления не исключает час из проверки температуры,
если выбранный температурный метод давления не требует. Для метода, использующего
температуру и давление совместно, проверяются оба требуемых входа.

Число и геометрия доноров определяются математическими требованиями метода
и заранее заданным сценарием опыта. Глобальное требование «полный год каждого
донора» или произвольное единое минимальное число доноров не вводится.

Если в этот час контрольного измерения нет, интерполяцию при доступных донорах
можно получить, но ошибку относительно неизвестного измерения оценить нельзя.
Такие предсказания учитываются в покрытии продукта отдельно от проверяемых ошибок.
Для пропущенного контроля не создаётся другой интерполяционный «эталон».

Годовые показатели полноты и требования к конечному годичному файлу остаются
отдельной задачей. Они не ограничивают исследовательскую выборку по часам.

## 2. Независимость контроля

При проверке выбранной площадки её значение не передаётся интерполятору.
Исключаются также связанные представления того же источника: объединённые ряды,
дублирующие каналы и производные величины, через которые может вернуться скрытая
контрольная информация. Простое различие ID не гарантирует независимости.

Датированные координаты, высоты, перемещения и определения временных интервалов
относятся к проверяемому часу. Последние координаты станции не заменяют историю
площадки. Часовые суммы радиации и осадков должны описывать сопоставимые интервалы;
метки с минутами, WOZ/MOZ и неразрешённое время не округляются молча до UTC-часа.

Параметры интерполятора, пороги и наборы доноров не подбираются по ошибке на том же
контрольном наблюдении. Для обучаемых поправок предусматривается независимое
разделение обучения и проверки по площадкам и временным блокам.

## 3. QC: автоматически проверенное значение не является ошибочным

Автоматически и вручную проверенные непустые значения входят в основную
исследовательскую выборку. Отсутствие ручной проверки не является причиной
объявлять значение неверным, исключать весь год или произвольно уменьшать вес.

Для GeoSphere `q21` сохраняются две оси статуса:

| Коды | Вид проверки | Состояние значения по метаданным |
|---|---|---|
| 10 | Автоматическая | Исходное состояние не уточнено |
| 11 | Автоматическая | Изменено |
| 12 | Автоматическая | Исходное |
| 20 | Ручная | Исходное состояние не уточнено |
| 21 | Ручная | Изменено |
| 22 | Ручная | Исходное |
| 0 | Не проверено | Отдельная категория |
| NULL / неизвестный код | Не определено | Отдельная категория |

Коды 0, NULL и неизвестные коды не объявляются ошибочными автоматически. Они
не приравниваются к успешно проверенным: для непустых значений предусматривается
отдельный анализ чувствительности и явный учёт неопределённости.

Изменённое значение не объявляется неверным. Состояние original/changed/unknown
сохраняется независимо от automatic/manual. Для оценки зависимости от происхождения
контроля отдельно показывается подвыборка original (12/22); changed (11/21) и
unknown (10/20) также учитываются и описываются. Возможное исправление или дополнение
поставщиком не маскируется под независимо подтверждённое исходное измерение.

Флаг относится к конкретной величине и часу. Заполненный флаг при пустом значении
не создаёт измерения. Значения разных стран интерпретируются по своим словарям;
номера DWD QN не приравниваются к численно похожим кодам GeoSphere.

Источник кодов: сохранённые метаданные GeoSphere `q21` в австрийском загрузчике,
а также официальный changelog Dataset API:
https://dataset.api.hub.geosphere.at/v1/docs/changelog.html .
Кодовая схема применяется при наличии соответствующего указания в метаданных
источника; отсутствующие ссылки на схему не заменяются догадкой.

## 4. Сравнение точности и покрытия

Для каждой величины обозначим через E множество доступных контрольных наблюдений
в заданной области опыта. Оно задаётся до сравнения ошибок, по общим правилам
наличия контроля, времени, независимости и QC-категории.

Метод m даёт допустимый результат на подмножестве V_m из E. Покрытие метода:

    C_m = |V_m| / |E|.

Дополнительно показываются доля доступного контроля относительно запрошенного
календарного периода и площадь/сезоны/часы, к которым относится опыт. Покрытие
наблюдаемого контроля и покрытие интерполятора — разные показатели.

Точность двух методов сравнивается на одинаковых контрольных наблюдениях:

    V_common = V_a intersection V_b.

На общем наборе считаются MAE, RMSE, средняя знаковая ошибка, квантили абсолютной
ошибки и парная разница методов. Отдельно можно показать ошибку каждого метода на
всём V_m вместе с числом часов и составом выборки; эти разные наборы сами по себе
не дают честного ранжирования точности.

При общем эксперименте пространственных весов доступный пул доноров одинаков,
чтобы изменение результата можно было связать с проверяемым методом. При опытах
с разными стратегиями выбора доноров их различие является частью метода и
отдельно описывается. Тестируются фактические сценарии числа/расстояния/высоты
доноров и частичного покрытия; невозможный расчёт фиксируется как отсутствие
результата с причиной, а не заменяется скрытым запасным методом.

Результаты разбиваются по площадкам, сезонам, времени суток, высоте, числу и
дальности доноров и погодным режимам. Вместе с общей ошибкой по всем часам
показываются показатели по площадкам, чтобы длинные и плотные ряды не скрывали
поведение в слабо представленных условиях. Неопределённость парной разницы
оценивается с учётом временных и пространственных зависимостей; отдельные часы
не объявляются автоматически независимыми статистическими повторениями.

## 5. QC как фактор анализа и научной дискуссии

Основной результат включает автоматически и вручную проверенные часы.
В разрезе QC отдельно учитываются статус контрольного значения, состав QC доноров
и original/changed/unknown. Сообщаются N, покрытие, MAE, RMSE, смещение и хвосты
ошибки; дополнительный разброс исследуется как наблюдаемый результат.

Большая ошибка в автоматической категории сама по себе не доказывает неверность
этих измерений. Категории могут отличаться по станциям, сезонам, погоде,
расстояниям и доступности доноров. Для обсуждения возможной роли QC используются
сопоставимые условия, анализ чувствительности и явные ограничения причинного вывода.
Гипотеза о связи QC с разбросом не превращается в заранее заданное исключение данных.

## 6. Минимальная запись отдельного проверяемого случая

Для воспроизводимости сохраняются: source snapshot/hash; площадка и её группа
происхождения; величина и единица; исходное и разрешённое время; контрольное
значение с QC/происхождением; ID, координаты и доступные значения доноров с их QC;
метод/версия/параметры; результат либо причина отказа; принадлежность к общему
набору сравнения; ошибка. Все изменения состава выборки имеют явную причину.

Этот документ фиксирует методику будущих испытаний. Он не объявляет выполненными
эксперименты, не изменяет результаты прежних отчётов и не меняет алгоритмы H1/S1/F1
или правила допуска конечного климатического продукта без отдельной реализации.
