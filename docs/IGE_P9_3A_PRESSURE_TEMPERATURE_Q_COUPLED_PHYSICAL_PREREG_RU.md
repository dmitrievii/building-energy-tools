# IGE P9.3A — Joint Pressure–Temperature–Specific-Humidity Physical Closure

**Research preregistration, 18 October 2026, BEFORE examining original 2014 outputs.** Project geography remains Austria/Germany/Switzerland only; this pilot specifically Graz / same frozen NASA CanESM5 grid and ERA5 donor coordinate. `main` untouched.

## Source semantics (non-negotiable)

Native NASA NEX-GDDP-CMIP6 v2 outputs **nine daily fields** `tas,tasmax,tasmin,huss,hurs,pr,rsds,rlds,sfcWind`, with NO contemporaneous `ps` pressure. NASA technical note and Thrasher et al. (2022) describe daily bias correction and spatial disaggregation. There is **no physical guarantee that separately downscaled daily T, huss and hurs can be reconciled at a local ERA5-like pressure or any fixed 24h T-profile**. Never "solve" pressure from the target humidity and claim it is native GCM pressure. Source-native `huss` remains original and unchanged, and `hurs` must be explicitly classified attainable/soft/unattainable. Original real 2013 blockers, 6 named days, remain development cases only.

Scientific equations: `q=e·eps/(p−(1−eps)e)`, `e=q·p/(eps+(1−eps)q)`, `RH=100e/e_s(T)`, `q_sat=e_s(T)·eps/(p−(1−eps)e_s(T))`. All pressures absolute Pa, temperatures °C, q kg/kg; retain original P9.2B Buck-over-liquid formulation for apples-to-apples compatibility. Below-freezing ice-vs-water saturation is a **separately flagged model-definition uncertainty**; no post-hoc switching to improve known original years.

## Frozen algorithm BEFORE original heldout year

1. Input original 12-vector hourly ERA5 donor and its **unchanged, time-varying `surface_pressure`** (hPa -> Pa); pressure provenance `ERA5 Open-Meteo grid source, not native NEX GCM ps`. Optional future `native GCM ps` is a *strict separate mode* which must block if source-certified `ps` not supplied; no invented pressure offset, no site elevation correction for success, no optimization of P. Required `p_h` within original observed ERA5 physical range.
2. Preserve target native exact daily `tasmean,tasmin,tasmax`. Start P9.2B monotonic 24h donor-temperature transform. If native `huss` fits hourly `q_sat` capacity, leave temperature unchanged.
3. If original donor T-shape cannot hold `huss`, apply one **constrained, minimal 24h T perturbation**: minimize original-profile deviation and variation of deviations, subject to exact native daily Tmean,min,max, unchanged original extrema time indices, T in native range, a conservative fixed **±2.0°C** absolute change per hour relative to existing morph, and a saturated-water capacity inequality `sum(q_sat(T_h,P_h))≥24·huss` with a numerical margin. Also cap hourly adjacent `T` change by `max(6°C/h, native baseline max adjacent jump)`. This is a **methodological prior, not a fit to original 2013 blocked dates**; failures remain blocked. Use deterministic SciPy SLSQP with pinned indices; no pressure fitting or seed sweep. Confirm resulting solution independently after optimizer reports success; do not trust solver status alone. No adjustment for already feasible T profiles, to minimize distortion.
4. Use P9.2B original nonindependent native daily GHI/rain/wind/LW solver with optional independently obtained admissible T-profile. Then P9.2C physical humidity reconciliation redistributes hourly q at unchanged native total `sum(q)=24·huss`, `0<q≤q_sat(T_h,p_h)`, and tries to attain native daily `hurs`. If mathematically unattainable, report residual, never clamp native `huss` or pressure.
5. For a **single-source-day** produce explicit pressure-source tag, native target-data SHA lineage, T profile maximum adjustment, hourly maximum T gradient and hard native daily residuals; fail-closed if none of the 2019/2020 same-month same-wet/dry donors qualifies. Pick between **fully qualified candidates only** by frozen P9.2B weather-seam weights and seed 7313; never inspect independent station errors. For computational tractability pre-screen original baseline donors and attempt only the **eight lowest saturation-deficit** repair candidates on a day with no feasible original donor; rank purely by *source q-capacity shortfall*, not post-outcome fit. This fixed cap is a methodological limitation, explicitly report it.
6. Keep `P9_3A_model_research_qualified=false` until full-year original GCM and observed pressure/humidity standards validate, regardless of generated EPW format.
