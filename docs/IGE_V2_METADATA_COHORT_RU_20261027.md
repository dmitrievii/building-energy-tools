# V2-M0/M1 — конкретная выборка по метаданным и прежнему раскрытию

27.10.2026. Функция продукта — A, локальная историческая температура, и последующая многолетняя база B-M. Исходная ветка V1A `8320428593cbb27418581e56fc43176d46fe6337` сохранена. На этом этапе разрешены только метаданные; модели, T наблюдений и временные ряды target QC не запрашиваются. Независимая точность и production не квалифицируются.

## Зафиксированный круг проверки

Проверено 850 сохранённых текстовых файлов точного V1A-коммита и оригинальный агрегат прежнего P8.4B3 с provenance. В исторически доступных каталогах 2019: AT 270, DE 475, CH 148 станций. После консервативного исключения явных прежних/резервных IDs, возможного использования в коде, известного CH контейнерного scope 2010–2019 и физических aliases остаются AT 223, DE 448, CH 63 кандидата для метаданных. Упоминание в коде не называется доказательством фактической загрузки. Отсутствие совпадения не считается глобальным доказательством неиспользования.

Сохранённые каталоги A1.1/V1 используются с исходными хешами; отбираются записи с полным каталожным покрытием 2019. Не прочитанные ранее станции не определяются по ошибкам, погодным значениям или их доступности. Полные raw-контейнеры учитываются вместе с другими переменными и неиспользованными годами. Ранее раскрытый полный CH wind census 2020–2029 не выдаётся за новую слепую выборку; его 159 станций не объявляются автоматически прочитанными в другом контейнере 2010–2019. Прежние wind-target identities исключены отдельно независимо от года и величины.

Старый дизайн V1A не определял конечный объём проверки датированных датчиков: 893 каталожные станции невозможно проверить новыми запросами при лимите 240. Поэтому до новой погоды оформлено отдельное уточнение M0 `v2_metadata_discovery_amendment_20261027.json`. Родительский дизайн не переписывается.

Фиксируются первые **18 физических идентичностей на страну** по SHA256 строки `IGE_V2_2019|station_key|20261027`, затем station key, после консервативного exposure-фильтра. Сначала устраняются aliases. Это **54 metadata candidates, не 54 цели**. При отказах круг не пополняется. Массив и все исключения сохранены в `v2_metadata_frame_20261027.json` и `v2_exposure_audit_20261027.json`.

## Датированная геометрия и выбор целей

На фиксированном круге проверяются оригинальные истории приборов/координат и конкретного T-параметра. Допуск — ровно 2 м над local/natural ground; сообщённая WMDR z не увеличивается повторно на AGL. Требуется полный интервал 10 января — 16 октября 2019; для CH начало расширяется на 50 минут и парсером консервативно до целого предыдущего часа. Частичные/неоднозначные deployment periods не объединяются без доказанной сегментированной схемы.

AT: словарь WMO ищется по первому значимому нормализованному слову названия; максимум три WSI-кандидата по опубликованному name-score и WSI. Только единственный датированный результат в пределах 500 м может быть допущен. Связь GeoSphere-ID/WMO здесь **выводится из имени и геометрии**, она не выдаётся за официальный crosswalk. Неоднозначность и отсутствие истории остаются отказами. DE: отдельный metadata ZIP 10min TT_10 с датированными geography/device/parameter; определение обычного hourly TT_TU не переносится. CH: используется WSI, опубликованный MeteoSwiss. Все фактические высоты и отказы сохраняются.

Из допущенных в этом конечном круге кандидатов внутри страны формируются три относительные страты по рангу номинальной высоты (`array_split`). В каждой выбираются первые две цели по прежнему hash-order. Это относительные ранги конечного круга, не физические климатические зоны и не репрезентативная глобальная выборка.

Затем все выбранные цели и aliases исключаются из доноров. Проверяется прежний фиксированный круг ближайших 8 AT / 4 DE и CH кандидатов в 5–150 км; берутся первые три metadata-admitted, минимум два. Ни QC-значения, ни температуры при этом не используются. Если не хватает шести целей в стране либо двух доноров у цели, исходный отказ сохраняется и раскрытие не начинается. Изменения возможны только новой явно версионированной постановкой до погоды.

## Что означает готовность этого этапа

Успешный M1 создаёт конкретные IDs целей/доноров, epochs, временные определения, исходные метаданные и журнал отказов. Это вход для **исполняемой регистрации V2**, а не разрешение немедленного unblinding. Пока не заморожены новый исполнитель, source URL manifest/budgets и actual prediction seal, weather acquisition остаётся запрещённым.

План V2 сохраняет 2019 год, четыре недели 10–16 января/апреля/июля/октября, шесть целей на страну: 72 случая и 12 096 запрошенных часов. AT QC10 относится к опубликованному автоматически проверенному продукту с неизвестной исходностью; исходный V1 QC22 и восемь AT отказов не меняются. DE QN3 и CH published-no-row-QC сохраняются отдельными стратами. R1 IDW2, min2, первичный парный MAE и учёт всех ухудшений/отказов остаются прежними. B4, P2, C2, NASA daily closure и EPW не получают нового допуска.

## Исполнение и сохранение оригиналов

`v2_metadata.py` имеет только разрешённые WMO/DWD metadata URLs и не принимает weather endpoints. Повторный запрос того же URL не выполняется. Лимиты: 240 новых HTTP attempts, одна попытка на URL, до 4 MB допущенного тела, 50 MB суммарного чтения; для выявления превышения используется один дополнительный контрольный байт, который сохраняется как отказ, не допускается. Старые проверенные metadata originals могут переиспользоваться с прежними квитанциями. Socket timeout 45 s не выдаётся за полный elapsed deadline; CI имеет отдельный лимит 35 минут.

Все полученные тела, включая отвергнутую metadata schema, сохраняются с URL/SHA/headers/квитанцией. DWD metadata ZIP проверяется на отсутствие продуктовых members. Пакет делится на части ≤5.5 MB с полным SHA; старые результаты и оригиналы не перезаписываются.

Отдельный workflow сначала проверяет офлайн зафиксированный круг и запрет weather I/O, затем получает метаданные, повторно восстанавливает все решения без сети из оригиналов и проверяет upload/download артефакта по каждому member SHA. Публикация источников допускается только в `research/ige-v2-metadata-exposure-cohort-20261027`, с проверкой исходного head и обычным non-force push, без merge и без main.

## Четыре отдельных статуса

| Ось | Допустимый вывод |
|---|---|
| Код | Офлайн-тесты, хеши и воспроизведение решений из metadata originals |
| Физическая допустимость | Датированный T2m и номинальный оператор; true instrument filter и вертикальные датумы отдельно |
| Независимая точность | Не измеряется: новых target T, QC series или моделей нет; глобальная слепота не сертифицирована |
| Эксплуатация | R1 не становится default; EnergyPlus, полный год, многолетняя база и production отдельно |

Фактическое получение метаданных завершено в CI #40490972489: 18 целей, 72/72 случая с допустимым составом доноров. Первый CI остановился на сравнении Python tuple с опубликованным JSON array; первоначальные данные и результат не менялись. Исправлена только проверка сериализованного представления, с тестом, который по-прежнему отвергает изменение веса на 1e-12. Локально 26/26 PASS и точный офлайн-повтор всех исходных metadata decisions. Следующий CI повторяет те же оригиналы без новых provider requests. Полная исполняемая weather-регистрация ещё не завершена.
