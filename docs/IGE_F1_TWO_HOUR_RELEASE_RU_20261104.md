# F1: ограниченное восстановление пропусков до двух часов

Дата: 4 ноября 2026. Назначение: ограниченный рабочий режим Climate Analyzer.

## Изменение поведения

В панели **Future climate from a selected base**, для допущенной станционной
интерполированной точки, по умолчанию выбирается
**Station point reference — recover gaps up to 2 h**.
Прежний строгий **Same-chain multi-year station point reference** доступен
в том же списке. Для EPW и сеточных баз выбор режима не изменён.

Для многолетней станционной базы F1 разрешается оценить только эпизод
не более двух последовательных часовых состояний. Эпизод определяется по
объединённой маске отсутствующих T/RH/p: чередующиеся пропуски разных
полей не позволяют обойти предел. Три часа не разбиваются на более короткие
задачи. На краях года требуются исходные наблюдения с обеих сторон.
Год возвращается целиком либо остаётся заблокирован: частично исправленный
донор при последующем отказе не публикуется.

Сохраняются четыре фиксированные исходные станции, годовой предел 1%,
проверка качества и определений H1, исходные высоты и временные операторы,
абсолютное станционное давление, Buck liquid-water конвенция, прежние
accuracy-пороги, контрольные окна и отказ при выходе за физические границы.
Восстановленные значения не становятся исходными донорами. Значения с
отклонённым QC и недопустимыми определениями не исправляются этим методом.

Величины T/RH/p/e в источниках остаются неизменными. Произведённые оценки
содержатся в отдельном журнале со станцией, полем, часом, значением и
результатами локальной проверки. В EPW указывается применение режима.
Остальные величины погоды сохраняют свои прежние источники.

## Версия и воспроизводимость

Политика: `PEER_ANOMALY_MASKED_WINDOWS_2H_V2`, максимальная длина — 2 ч.
Версия входит в ключ кеша и манифест многолетней базы; предел дополнительно
записывается и проверяется в архиве. Старые пакеты режима V1 с пределом 72 ч
не принимаются как новая база. Строгий режим также не принимает архив с
восстановлением. Исходные годовые ответы можно обработать заново.

Прежние научные отчёты и численные результаты сохранены. Для повторения
аудита версии V1 следует использовать его зафиксированный коммит
`cada084eec53e4aa7408df11310580921df620db`: runner намеренно проверяет SHA
исходников и не выдаёт исследование V1 за проверку изменённой политики V2.

## Объём допуска

| Уровень | Статус |
| --- | --- |
| Код | Новые тесты проверяют предел 1/2/3 ч, общую маску полей, края года, годовой бюджет, атомарность, физический отказ и несовместимость архивов. |
| Физическая допустимость | Сохраняется проверка с отказом; RH не обрезается. |
| Независимая точность | Не квалифицирована. Это ограниченное эксплуатационное решение на основании раскрытого аудита, а не новая станционная валидация. |
| Приложение | Ограниченный режим доступен пользователю после переноса обновления в main и обновления Streamlit. Научный статус результатов остаётся исследовательским. |

Случаи 2015 и 2016 с двухчасовыми пропусками остаются положительными
проверками полного исторического EPW на 8760 и 8784 ч. Пропуск 61 ч 2014 года
теперь отвергается до оценки значений по пределу длительности. Полный будущий
EPW Graz 2012–2021 этим обновлением не сформирован и не обещан.

Ограничение относится к построению многолетней станционной базы F1.
H1 по-прежнему показывает полноту исходных наблюдений; общий поиск доноров
S1 не получает скрытого автоматического восстановления. Датчики, высотные
поправки, NASA-определения, морфинг и существующий анализ EPW не изменены.

В релиз включены необходимые предшествующие компоненты PR #124–126:
полнота станций и исходная метаинформация, фиксированная многолетняя сеть F1,
журнал восстановления и аудит. Изменения, уже находящиеся в main, включая
EPB Visualizer, сохранены.

## Предрелизная проверка

816/816 тестов, без пропусков и ошибок. Воспроизведены четыре годовых
продукта по 8760 ч, станционные и будущие контрольные примеры, проверен
запуск Streamlit из корня репозитория. Проверено 163 зафиксированных файла
и соответствие установленным зависимостям Cloud. Новых погодных запросов
при этой проверке не выполнялось. Результаты сохранены в
`deployment/audits/ige-gap-two-hour-release-20261104/verification.json`.
