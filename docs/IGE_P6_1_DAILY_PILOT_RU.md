# IGE Climate Engine — P6.1: синхронные суточные данные CMIP6

Дата начала: 2026-10-10. Статус: пилотный исследовательский workflow; **не** готовый генератор EPW.

## Переход от P5 к P6

В P5 восьмимодельные месячные данные GHI (NASA NEX-GDDP-CMIP6 rsds) сопоставлялись с отдельными ансамблевыми месячными значениями температуры и осадков (World Bank CCKP). Эти показатели не образуют совместный метеорологический ряд. P6 получает данные для каждой переменной **из одной модели, одного члена и одной временной реализации**, сохраняя дневную ось CF.

## Пилот

Модель ACCESS-CM2, member r1i1p1f1, Graz (46.983 N, 15.450 E). Исторический 2014 и SSP2-4.5 2050 — только тестовые годы для проверки технологического пути; НЕ климатические нормы и НЕ прогноз конкретной погоды 2050 года.

Девять доступных полей NASA v2.0: tas, tasmin, tasmax, hurs, huss, pr, rsds, rlds, sfcWind. Последнее — **скорость** ветра без направления. Каждый NetCDF source URL и SHA-256 записывается. Отдельные исходные значения не заменяются месячными медианами.

Скрипт: research/ige_cmip6/p6_daily_multivariable.py. Артефакт GitHub Actions: joint_daily_raw.csv, daily_qa.json, source_provenance.json. Для двух пилотных годов ожидается 18 NCSS запросов — по девять на год — и 730/731 записей в зависимости от календаря. GitHub CI выводит фактический итог; до завершения job результата **нет**.

## Проверочные условия

- Никаких пропусков или дубликатов дневных отметок; даты всех переменных совпадают.
- Проверка временного календаря (Gregorian, noleap, 360-day), общих координат ячейки, модели, члена, сценария.
- Сохранение единиц NASA и проверка физических диапазонов, в том числе tasmin <= tas <= tasmax с допуском 0.25 K.
- Пересчёты: осадки кг·м⁻²·с⁻¹ × 86400 = мм/сут, радиация Вт·м⁻² × 0.024 = кВт·ч·м⁻²·сут⁻¹.
- При несоответствии выполнение **останавливается**, отсутствующие данные не заполняются искусственно.

## Ограничения и следующий этап

Синхронный суточный индекс необходим, но ещё **недостаточен** для физической согласованности после даунскейлинга и коррекции. Точки GCM и GeoSphere не совпадают; давление для независимой психрометрической проверки отсутствует; направление ветра и DNI/DHI не получены; почасовых данных и EPW нет.

После положительного пилота: получение 1995–2014 и двух двадцатилетних будущих окон для SSP2-4.5/SSP5-8.5; затем распространение на все восемь GCM, независимая наземная валидация сезонного хода, экстремумов, корреляций и физического баланса. **Только после этого** совместная bias correction (P6.2) и почасовая генерация (P6.3). Production Climate Analyzer main не изменяется.
