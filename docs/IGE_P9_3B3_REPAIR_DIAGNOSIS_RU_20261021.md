## Что оказалось причиной пяти UNRESOLVED

Локальный SLSQP не давал свидетеля, но его отказ ничего не доказывал. Добавлены общие внешние границы, применимые к произвольной форме температуры в интервале Tmin–Tmax, при фиксированных p и фазовом определении RH.

Для каждого узла i и положительных нормированных весов w_i:

- `e_i(q)=p_i q/[ε+(1−ε)q]`, `ε=Rd/Rv`;
- `RH_i=100 e_i(q_i)/es_phase(T_i)`;
- `L_i≤T_i≤U_i`, `0≤q_i≤c_i=qsat_water(U_i,p_i)`.

Поскольку e(q) вогнута, а es(T) возрастает:

`RH_i ≤ 100 e_i(q_i)/es_phase(L_i)`.

Максимум взвешенной суммы правых частей при `Σw_i q_i=Q` даёт глобальную верхнюю границу RH. Это separable concave maximization, решаемая условиями KKT с box caps c_i. Нижняя граница следует из хорды вогнутой e(q):

`RH_i ≥ [100 e_i(c_i)/(c_i es_phase(U_i))] q_i`.

Минимизация линейной правой части при той же массе — непрерывная knapsack LP. Границы учитывают численные допуски q/RH. Ограничения на среднюю T, градиенты и достижение экстремумов ослаблены; поэтому полученные сертификаты не зависят от локальной сходимости solver. Все допустимые доноры проходят проверку, а лимит восьми NLP применяется только к оставшимся несертифицированным кандидатам.

Локальный повторный census (тот же зарегистрированный NASA CSV, те же canonical ERA5 hashes, без изменения коэффициентов) дал:

Все пять получают `CERTIFIED_INFEASIBLE`, 727 прежних `EXACT_DEFINED_OPERATORS` сохранены. Счёт с граничными сутками: 2013 — 362 exact + 4 certified; 2014 — 365 exact + 1 certified. Время локального L3 census: около 63 и 59 s. Точные числа дополнительно проверяются в CI против исходного artifact.

**Область доказательства:** только зарегистрированные давления, выбранная source phase и определённые суточные операторы. Это не доказательство ошибки атмосферы, исходной GCM или всех возможных высот/давлений. NASA time/space averaging и отдельная обработка переменных могут быть причиной несовместимости наложенных ограничений; исходные данные не исправляются задним числом.

Strict mode сохраняет блокировку. Явный research reconciliation остаётся локальным кандидатом с полным журналом изменений, без глобального optimum и без научно оценённого correction budget. Изменения RH на 3–11 п.п. не превращаются в автоматически допустимый климат.

## Давление: две различные причины

Первый station benchmark переносил p вместе с донорскими сутками 2019/2020 и сравнивал с реальными датами 2021. Это не изолированная оценка pressure reference: в ошибку попадала разница синоптических событий. Даже синхронный ERA5 grid reference имел крупную ошибку в Давосе, то есть совпадение дат не устраняет проблему высотной системы.

1. В `generate` добавлен отдельный неизменяемый `pressure_by_date`. Проверяются точные ключи дат, `reference_date`, размерности и запрет observed station pressure. p не является переменной оптимизации. Donor-pressure mode сохранён и явно помечен как несинхронный; для будущего климата он не выдаётся за восстановленный native CanESM5 ps.
2. Новый coherent reconstruction benchmark использует p целевых суток ERA5. B3 и неизменённый P9.3A control получают одни и те же массивы p через явный adapter. Их равенство проверяется assertion по каждому выданному часу. Оба метода выбирают доноров независимо по суткам, без previous-day conditioning. Поэтому новый расчёт — отдельная зарегистрированная диагностика; его нельзя смешивать с прежними числами.
3. Дополнительно, отдельно от T–q–RH генерации, рассчитываются три pressure diagnostics на одинаковых часах: date-aligned ERA5 grid, MSL→site fixed lapse и isothermal sensitivity. Никакой вариант не выбирается по станционным ошибкам.

Для нового гидростатического кандидата задаются высота станции из исходных metadata и `Tv_site = T_proxy [1+(Rv/Rd−1)q_proxy]`. При постоянном q и линейном профиле T с Γ=0.0065 K/m:

`p_site = p_MSL [Tv_site/(Tv_site+Γ_v z_site)]^[g/(Rd Γ_v)]`, где `Γ_v=Γ[1+(Rv/Rd−1)q_proxy]`.

Изотермическая sensitivity: `p_site=p_MSL exp[−g z_site/(Rd Tv_site)]`.

Используются фиксированные `g=9.80665 m/s²`, `Rd=287.05 J/(kg K)`. Источник MSL — отдельный запрос `models=era5`, тот же nearest grid, `elevation=nan`, проверка единиц, координат, временной оси и SHA. T/q сетки служат **непроверенными proxy для колонки над станцией**; алгоритм редукции MSL поставщика и фактическая вертикальная стратификация остаются ограничениями. При отсутствии высоты/исходного MSL ячейка blocked. MSL не подставляется непосредственно вместо станционного p. **Новый кандидат не интегрирован автоматически в термодинамическое состояние на высоте станции**: для этого нужна согласованная вертикальная модель T/q.

DWD semantics B2D сохраняются: `P0_ST_10` — станционное, `PP_ST_10` — морское. B4 остаётся NOT QUALIFIED. Новый расчёт не заменяет отрицательный B2D результат.

## Временные операторы NASA

Новый adapter читает фактические 365 координат `time` и проверяет calendar/origin, принадлежность году, шаг и полуденные метки. Ссылка `bounds` в DAS проверяется по реальному DDS. Значения bounds читаются только при наличии переменной и отдельно валидируются; полуденная метка не доказывает интервал усреднения.

Статусы различают:

- реальные прочитанные и проверенные bounds;
- отсутствующее объявление bounds;
- dangling attribute: bounds объявлены, но переменной в DDS нет;
- bounds объявлены/имеются, но значения не прочитаны;
- сетевой или schema blocker.

Локальная ограниченная проверка прочитала координаты hurs/huss 2014 и выявила dangling `time_bnds` у tasmax 2014. Остальные запросы частично дали HTTP 500/503. Ранее отдельно прочитанные первые три координаты tas/hurs/huss 2013 совпали: 59495.5, 59496.5, 59497.5 при календаре 365_day и origin 1850-01-01. Это подтверждает alignment меток, а не общий интервал усреднения.

`tas` сохраняет оператор derived midrange. Унаследованный `cell_methods: time: maximum` не становится оператором temporal mean; численная проверка 730 суток и source comment сохраняются. Полная NASA interval qualification остаётся false. Новый JSON фиксирует source statuses/URL/SHA, CI повторяет проверку 2013/2014 с ограниченным числом запросов.

## Проверки и интерпретация результатов

Локально: 74 теста P9.3B3 PASS (включая 120 constructed admissible states внутри одного oracle test), 72 прежних теста PASS, B2D pressure-field contracts PASS. Новый integration test запускает реальные B3 и P9.3A algorithms на synthetic weather через тот же runner, проверяет общее давление, sealing/scoring и отсутствие production qualification. Синтетическая сетка/pressure stress проверяются повторно.

CI отдельно выполняет полный исходный annual ablation census и неизменённый 28-day pilot, сравнивает новые L3 диагнозы с immutable first-run artifact, читает native source time и повторяет AT/DE/CH diagnostics. GPU не нужен; 3 jobs, лимиты 12/90/90 min. Ожидаемый общий wall time порядка 15–35 min, без гарантии при внешних сбоях источников. После запуска CI не опрашивается в цикле.

2021 окна уже раскрыты первым запуском. Повторная диагностика **не является новым независимым holdout**. Все три pressure variants, неуспешные ячейки и старые отрицательные результаты сохраняются; порог 2 hPa не меняется. Не расширяются страны, станции или периоды.
