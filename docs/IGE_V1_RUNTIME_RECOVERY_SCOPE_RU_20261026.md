# V1: сохранение исполнения после недоступности локальной среды

Среда локального исполнения стала недоступна после успешного расчёта метрик, до публикации полного контрольного пакета и завершения проверки. В GitHub уже находятся регистрация, исходные прогнозы, полный predictor-пакет и код научного метода.

Recovery workflow повторно получает те же зарегистрированные endpoints и сохраняет новые оригиналы, исходную численную сводку, фактический пересчёт и CI-артефакт. Старые математические модули, QC, временные операторы, выборка и actual prediction seal не меняются. AT-контроли остаются закрытыми. Новая загрузка не объявляется новым независимым экспериментом.

Первый локальный контрольный ZIP: SHA256 b85f06538bb3b3f8cedc5542477bdd440dad522e3d856333d3507349ee76eb9d. Его побайтовая идентичность новым телам не сертифицируется без доступа к первому ZIP. Доступные первоначальные численные метрики сохранены отдельным JSON и сравниваются с новым пересчётом; все расхождения будут опубликованы, без выбора более выгодной версии.

Общий климатический бюджет 900 MB сохраняется, включая 243864017 bytes первого исполнения и все повторные попытки восстановления. Транспортный wrapper ограничивает только оставшийся бюджет; научные уравнения и критерии допуска не меняются.

CI проверяет 300 родительских тестов, 42 V1 и 8 pre-control gate, пересчитывает прогнозы и ошибки из оригиналов, загружает и повторно скачивает артефакт с проверкой всех файлов по SHA256. Результаты записываются в ту же исследовательскую ветку после этих проверок; main, старые результаты, EPW и merge не затрагиваются.
