# Пути Windows в конфигурациях — исправление 0.1.1

Для структуры с папками `Database`, `IGE_Automatic_Regression_v0_1_0` и
`IGE_Climate_Experiments_E0_E10_v0_1_0` внутри общего `Climate` оба расчётных
каталога используют один и тот же путь к базе:

```json
"database": "../Database",
```

Абсолютный путь для показанной пользователем структуры также корректен:

```json
"database": "E:/User Folder/Documents/00_TU Graz/Dissertation/IGE/Climate/Database",
```

Измените эту строку **в обоих файлах**: `config_E0_E10.json` и
`config_auto_regression.json`, каждый в соответствующей папке программы.
Сохраните запятую в конце, поскольку далее идёт поле `results`. Остальные
настройки оставьте прежними. Одиночные `\` в JSON могут приводить как к
`Invalid \\escape`, так и к скрытому превращению `\t`, `\n` или `\r` в
управляющие символы. Самый простой вариант для путей в JSON — `/`.

NumPy/SciPy из приведённого журнала установились успешно. Предупреждение о
сетевом тайм-ауте было обработано повторным запросом. Обновление pip для
исправления конфигурации не требуется.

## Установка дополнения

Распакуйте содержимое дополнения в **каждую из двух папок программы**, разрешив
замену программных файлов. Конфигурации и данные в архив дополнения не включены:
ваши настройки и исходные наблюдения сохраняются.

Версия 0.1.1 добавляет понятную диагностику JSON с именем файла, строкой и
столбцом и отдельно обнаруживает управляющие символы в путях. Ошибочные JSON
автоматически не переписываются. Строгое чтение планов, receipts и научных
результатов остаётся прежним.

Проверить конфигурацию без расчёта и записи результатов:

```bat
python ige_experiments.py check-config --config config_E0_E10.json
python ige_regression.py check-config --config config_auto_regression.json
```

В каждой папке используйте команду своей программы. Успех обозначается
`"configuration_valid": true`. Проверка автоматической регрессии не требует
NumPy/SciPy. Обновлённый `RUN_AUTO_REGRESSION.bat` выполняет её до установки
зависимостей. После исправления путей запускайте прежние BAT-файлы.

Расчётные методы, коэффициенты, выборки и правила допуска данных этим
обновлением не меняются. Полная программа нужна из предыдущей поставки;
данный архив является дополнением, а не самостоятельной установкой.
