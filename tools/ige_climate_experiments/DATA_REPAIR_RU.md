# E0 — учёт проверенных замен DWD, версия 0.1.2

Обновление применяется к обеим расчётным папкам: автоматической регрессии и
E0/E1.0. Распакуйте содержимое дополнения в каждую папку с заменой программных
файлов. Пользовательские JSON-конфигурации и файлы Database в архив не включены.

E0 сохраняет исходные статусы всех версий заданий. Для дополнительных планов
`germany_recover.py` теперь проверяются исходный plan ID, неизменность станции,
продукта, периода и геометрии, однозначность связей заданий, хеши сохранённых
HTML-индексов DWD и соответствие им размера и даты ZIP. Только после этого
подтверждённая версия может закрыть повреждённую или ожидаемую старую версию.

В `jobs.csv` добавлены `effective_status`, `resolved_by_plan_id`,
`resolved_by_job_id`. Нативный `QUARANTINED` сохраняется; при проверенной замене
эффективный статус равен `REPLACED_BY_VERIFIED_JOB`. Исходные ошибочные файлы
остаются в Database и продолжают быть видимыми в отчёте.

В сводке DE добавлены `replaced_pending_jobs`, `replaced_quarantined_jobs`,
`unresolved_pending_jobs`, `unresolved_quarantined_jobs`. В `recovery_resolution`
показана уникальная готовность исходного плана. Число всех версий 4529 после
дополнительной догрузки не следует сравнивать с 4478 уникальными заданиями.

Нерешённый карантин и ошибки происхождения по-прежнему дают код 2. Старая
повреждённая версия с проверенной заменой сама по себе больше не блокирует run.
Никакие повреждённые артефакты не попадают в численные входы. Проверки SHA-256,
времени, строк и QC не отключаются.

## Следующий запуск

Сначала восстановите GRE через `switzerland_repair.py` в `Database/CH`.
Успешная немецкая догрузка уже закрыла 4478 из 4478 исходных заданий.
Затем в папке расчётной программы запустите только аудит:

```bat
python ige_experiments.py audit --config config_E0_E10.json
```

Обычный запуск использует свой кэш хешей неизменившихся файлов. `--rehash`
для этой проверки не нужен. Проверьте `source_data_errors: false` в общей
сводке, `all_jobs_resolved: true` у исходного DE-плана и
`unresolved_quarantined_jobs: 0` у DE. Для CH ожидается 587 проверенных заданий
без карантина; успешность чтения GRE также проверена на приложенном исходнике.

Старый run сохраните как результат D/V. Новый fit создавайте отдельным запуском
после подготовки следующего эксперимента влажности. C за 2025 год остаётся
закрытой. Алгоритмы интерполяции, обучающие выборки и веса QC этим обновлением
не меняются. Сравнение полных цепочек влажности ещё не реализовано.

Старые запечатанные модели привязаны к точным хешам реализации 0.1.0.
Обновлённый код 0.1.2 предназначен для новых run; хеши старых моделей не правятся.
Исходную реализацию можно восстановить по зафиксированному commit 634a794.
