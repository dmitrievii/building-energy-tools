# Проверка автоматических регрессий v0.1.0

2026-11-07. Машинные результаты: `validation/automatic_regression.json`.
Журнал полного набора: `validation/automatic_regression_tests.log`.

**109 тестов PASS**: 70 первоначальных E0/E1.0 и 39 новых тестов автоматических
регрессий. Локально: Linux, Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0.
Последний полный набор: 8.893 s. Локального запуска на Windows не было;
в GitHub предусмотрены Windows/Ubuntu с Python 3.10 и 3.13.

На синтетическом общем высотном поле выбран простой `height_idw_ols` для T/RH/p.
Для производного log(e) в этом примере выбран `harmonic_idw_ridge`. Это **не
результат сравнения методов на реальных климатических рядах**. Численно плоские
цели помечаются; найденный весовой параметр не называется физически уникальным.

Внутренние проверки сохраняют коэффициенты и ошибки по fold. Метрики V/C
содержат отдельные страны, станции, месяцы, QC, общие часы и собственное покрытие.
Доверительных интервалов для зависимых рядов эта версия не вычисляет.

Нативные реальные малые AT/DE/CH CSV и их происхождение проверяются прежними
70 тестами. В них проверены P0, единицы, QN/AT-флаги, отсутствие выдуманного QC CH,
разные временные операторы и повреждение источников. Эти fixtures не содержат
достаточного числа станций для самостоятельной новой научной калибровки.

Полная пользовательская Database недоступна в этом окружении и не обучалась.
Научная квалификация точности и полный старый replay P8.2F/S1/R1 не заявляются.

Повторить программные тесты:

```bat
python -m pip install -r requirements_regression.txt
python -m unittest discover -s tests -v
```

Повторить сохраняемый синтетический эксперимент в **новой** выходной папке:

```bat
python tests/validate_auto.py --out synthetic_validation_new
```

Во второй команде данные создаются искусственно и помечаются SYNTHETIC.
Нативные каталоги пользователя для неё не требуются. Получатся оба профиля,
отдельная оценка C и `engineering_evidence.json` с наблюдёнными результатами.
