# Скачивание австрийских станционных наблюдений

Загрузчик IGE для **GeoSphere Austria `klima-v2-1h`**. Python **3.10 или новее**,
только стандартная библиотека; `pip install` не требуется. Работает отдельно от
Streamlit. Это получение наблюдений и их координатной основы для последующей
интерполяции, а не сама интерполяция и не генератор EPW.

## Что включено

| Файл | Назначение |
|---|---|
| `austria_climate.py` | Каталог, поиск соседей, планирование, скачивание и экспорт |
| `catalog/stations.csv` | Готовый справочник ID, координат, высот и периодов площадок |
| `catalog/stations.geojson` | Те же станции для карты; координаты `[longitude, latitude]` |
| `catalog/metadata.original.json` | Исходный ответ GeoSphere без изменения байтов |
| `catalog/parameters.json` | Имена, описания, единицы и справочники кодов поставщика |
| `catalog/catalog_manifest.json` | Источник, время получения, SHA-256, лицензия и состав |
| `config_2016_2025.json` | План для последнего полного десятилетия 2016–2025 |
| `config_smoke.json` | Небольшая проверка: две площадки, одни сутки |
| `tests/` | Автономные проверки, включая сохранённый настоящий ответ API |

Поставляемый снимок получен **6 ноября 2026 года**. В нём 823 записи:
**616 отдельных площадок (`INDIVIDUAL`)** и **207 объединённых рядов (`COMBINED`)**.
Это не 823 независимые станции и не утверждение о наличии полного ряда для каждой.
Все 616 отдельных площадок включены в координатный справочник, в том числе закрытые.

## Быстрый запуск

Откройте терминал в этой папке. Команда `python` ниже должна запускать Python 3.10+;
в Windows можно использовать `py -3`, в Linux/macOS — `python3`.

Сначала выполните небольшой запрос:

```bash
python austria_climate.py plan --config config_smoke.json --out plan_smoke.json
python austria_climate.py download --plan plan_smoke.json --out downloaded
python austria_climate.py export --plan plan_smoke.json --out downloaded --station-id 16413 --year 2025 --plain-csv
```

Полученный CSV содержит **одни сутки**, а не полный 2025 год. Рядом создаётся
`2025.coverage.json`, где `full_calendar_axis=false`. Наличие файла с номером года
не означает полноту календарного года или допуск к EPW.

## Обновить каталог с координатами

```bash
python austria_climate.py catalog --out downloaded/catalog
```

Получаются CSV, GeoJSON, справочник параметров и точная копия метаданных.
При повторном обновлении прежние исходные метаданные сохраняются по SHA-256
в `snapshots/`. Для использования обновлённого каталога добавьте
`--catalog downloaded/catalog/metadata.original.json` к `nearest` или `plan`.
Без этого параметра используется поставляемый снимок.

## Найти ближайшие станции

```bash
python austria_climate.py nearest --lat 47.0707 --lon 15.4395 --date 2025-01-01 --limit 10 --radius-km 100 --csv nearest_graz.csv
```

Дата обязательна: координаты должны относиться к рассматриваемому периоду.
Учитываются `valid_from` и `valid_to`; современный признак `is_active` не подменяет
историю станции. По умолчанию поиск включает только отдельные площадки.

Опциональный отбор по опубликованной высоте:

```bash
python austria_climate.py nearest --lat 47.0707 --lon 15.4395 --date 2025-01-01 --elevation-m 360 --max-height-difference-m 500 --radius-km 100 --limit 10 --csv nearest_graz.csv
```

Радиус и высотный допуск — заданные пользователем фильтры, **не квалифицированные
коэффициенты интерполяции**. Расстояние рассчитывается по формуле гаверсинуса
на сфере со средним радиусом Земли 6371,0088 км; это географическое расстояние,
которое не описывает рельефные барьеры и репрезентативность площадки.

Для будущего исключения контрольной станции предусмотрены `--exclude-ids 16413`
и `--exclude-group 30`. Второй вариант убирает всю указанную группу объединённого
ряда. Поле `group_id` сохраняется для контроля связанного происхождения данных.
Близкие площадки могут иметь общую историю; перечень соседей ещё не является
допущенным независимым набором доноров.

Основные колонки координатного CSV:

- `station_id` — ID климатического ресурса GeoSphere, **не WMO-номер**;
- `latitude_deg`, `longitude_deg` — широта и долгота WGS84 / EPSG:4326;
- `elevation_m` — опубликованная высота станции; это не подтверждённая высота барометра или другого прибора;
- `station_type`, `group_id` — отдельная площадка или объединённый ряд и принадлежность к группе;
- `valid_from_utc`, `valid_to_utc` — опубликованный интервал площадки;
- `has_global_radiation`, `has_sunshine` — признаки каталога, не гарантия покрытия каждого часа;
- `metadata_sha256` — ссылка на точный снимок метаданных по его хешу.

## Скачать десятилетие

```bash
python austria_climate.py plan --config config_2016_2025.json --out plan_2016_2025.json
python austria_climate.py download --plan plan_2016_2025.json --out downloaded
```

Первая команда **не скачивает наблюдения**. Она фиксирует исходные метаданные,
площадки, даты, параметры, размеры запросов и их детерминированные идентификаторы.
Исходный JSON метаданных встроен в план с SHA-256, поэтому изменение каталога
после планирования не меняет этот расчёт.

На поставляемом снимке этот план включает 309 отдельных площадок, чьи интервалы
пересекают 2016–2025 годы, 40 полей с QC и 1310 запросов. Всего запрашивается
968 080 960 значений, включая потенциальные `null`. Это оценка размера запроса,
а не число реально существующих наблюдений.

Официальные ограничения на момент подготовки: 240 запросов/час, 5 запросов/с,
до 1 000 000 значений на JSON/CSV-запрос. Здесь предусмотрены пауза не менее
16 с между началами запросов и запас до 800 000 значений. Минимальное время
только по паузам для этого плана — **5 ч 49 мин**. Время ответа сервера,
повторные попытки и локальная запись увеличивают продолжительность.
Фактический объём полного десятилетия в этой поставке не измерен.

Не запускайте параллельные загрузки с одного адреса: ограничения поставщика
относятся к совокупному потоку запросов. Конкурирующие записи в один расчёт
блокируются файлом `.download.lock`.

Ограниченная первая порция:

```bash
python austria_climate.py download --plan plan_2016_2025.json --out downloaded --max-jobs 2
```

Повтор той же команды продолжает работу: завершённые запросы пропускаются
**только после проверки хешей исходного ответа и всех CSV**. В `download_summary.json`
показаны выполненные и оставшиеся запросы, ошибки — в `errors.jsonl`.
`Ctrl+C` снимает блокировку. После аварийного завершения процесса нужно убедиться,
что он остановлен, и удалить указанный в сообщении файл `.download.lock`.

При новом плане создаётся отдельная папка с его идентификатором. Старые планы и
исходные ответы другого расчёта не смешиваются. При возобновлении используется
сохранённая версия данных; для получения пересмотренных наблюдений используйте
новый выходной каталог. GeoSphere может менять исторические значения после QC.

## Выбрать годы, станции и величины

Отредактируйте копию JSON, например:

```json
{
  "start": "2020-01-01",
  "end": "2025-12-31",
  "station_kind": "individual",
  "station_ids": [16413, 16414],
  "parameters": ["tl", "rf", "p", "pred", "ff", "dd", "rr", "cglo"],
  "chunk_months": 3,
  "max_values": 800000,
  "min_interval_seconds": 16
}
```

Парные `_flag` добавляются автоматически. `parameters="all"` выбирает все поля
зафиксированного снимка. Возможны календарные блоки 1, 3, 6 или 12 месяцев.
Запросы обрезаются по опубликованным интервалам отдельных площадок, но доступность
значений проверяется только после ответа. Выбор площадок без пересечения периода
приводит к явному отказу, а не к фиктивному ряду.

Дата без времени означает UTC: начало в 00:00, конец в 23:00 включительно.
Для явного времени обязателен часовой пояс, например `2025-01-01T00:00:00Z`.
Работа ведётся в UTC без переходов DST. Суточное осреднение не выполняется.

## Формат результата

```text
downloaded/<plan_id>/
  plan.json
  metadata.original.json
  raw/<job_id>/<sha256>.json.gz
  csv/<station_id>/<year>/<job_id>.csv.gz
  receipts/<job_id>.json
  download_summary.json
  errors.jsonl
  stations/<station_id>/<year>.csv.gz
  stations/<station_id>/<year>.coverage.json
```

`raw` содержит gzip-сжатые исходные байты JSON; их SHA-256 проверяется после
распаковки по `original_response_sha256`. Сжатый файл имеет дополнительный хеш.
Для каждой площадки создаются CSV-части с исходными именами и единицами величин.
`null` становится пустой CSV-ячейкой. Пропуски не заполняются и не заменяются нулями.
QC-флаги сохраняются, включая 0, 10, 11, 12, 20, 21, 22 и отсутствие флага.
Флаг 10 означает автоматическую проверку; он сам по себе не подтверждает,
что значение никогда не было дополнено или изменено поставщиком.

Собрать загруженные части для одной станции и года:

```bash
python austria_climate.py export --plan plan_2016_2025.json --out downloaded --station-id 16413 --year 2025 --plain-csv
```

Без `--plain-csv` создаётся `.csv.gz`. Экспорт блокируется, если хотя бы одна
запланированная часть этой станции/года не скачана или повреждена. Отчёт явно
разделяет число строк, полный календарный год и непустые значения по параметрам.
При части года, неполной истории площадки или `null` не заявляется полноценный EPW.

## Смысл переменных и ограничения

Сохраняются опубликованные определения. В частности, `p` — давление на уровне
станции в hPa, `pred` — отдельная величина приведённого давления; они не заменяют
друг друга. `tl` и `rf` — опубликованные часовые измерения, `ff` и `dd` относятся
к векторному среднему за час, `rr` — сумме за час, `cglo` — среднему потоку W/m².
Полные определения сохранены в `parameters.json`. Преобразования в Pa, Wh/m²,
локальное стандартное время, расчёт влажности и физическое замыкание здесь
не выполняются.

Станционный ряд с QC не объявляется однородным многолетним климатическим рядом.
Для трендов необходимо отдельно рассматривать историю приборов и площадок,
гомогенизацию и сравнимость наблюдений. Для интерполяции необходимо отдельно
допустить временные операторы, QC, полноту и репрезентативность доноров.

Успешный запрос с полностью пустыми значениями — **успешная передача, отсутствие
наблюдений**. Повторять его бесконечно бессмысленно. В проверочном запросе
Graz Universität `16412` за 1 января 2025 года возвращает `null` для температуры
`tl`, а Graz Straßgang `16413` возвращает температуру во все 24 часа. Другие поля
площадки `16412`, включая давление и радиацию, в этом ответе присутствуют.
Это сохранённый диагностический
пример доступности, не оценка точности или пригодности интерполяции.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Проверяются география и порядок координат, исторические интервалы, исключение
групп, високосный год, UTC-ось, автоматическое включение QC, лимиты, единицы,
отказы при повреждении данных, сохранение `null`, возобновление и экспорт.
Полное десятилетие автоматически не запускается.
