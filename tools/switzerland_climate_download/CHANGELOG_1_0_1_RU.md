# Обновление 1.0.1 — повторная обработка сохранённого оригинала

Дата: 2026-11-07.

Пользователь сообщил 586/587 завершённых заданий в плане
`0dfa3011a5de4be6cf8021dbfae5124d012720234db9a732f298a935ec78ac3e`.
Запрос `b19771941413ebf24399eac2` относится к GRO (Grono), архиву
`ogd-smn_gro_h_historical_2020-2029.csv`.

Проверка того же опубликованного файла дала SHA-256
`9e4cdf7f83dece635cc58d01e8bf64865fd05ac301c6ec9467ba53ec329a8d5a`,
совпадающий с планом. Файл содержит 6 959 247 байт, 52 608 строк за 2020–2025,
36 полей, включая идентификатор и время. В этой среде строгий разбор и сохранение
успешны; нечисловых/бесконечных заполненных измерительных ячеек не обнаружено.
Причина сообщения `Expected a finite number` у пользователя **не воспроизведена**.
Это не основание исправлять, удалять или заменять значения погоды.

Изменения:

- При незавершённом запросе download сначала проверяет уже сохранённый raw gzip.
  Повторная обработка разрешена только при совпадении **распакованной** SHA-256
  с опубликованной контрольной суммой, зафиксированной в существующем плане.
- Повреждённый, слишком большой или не привязанный к provider SHA оригинал
  не принимается как проверенный кэш; остаётся обычный путь получения из сети.
- Ошибка числа теперь сообщает станцию, время, параметр, строку CSV и литерал.
  Строгая проверка не ослаблена; NaN/Inf/произвольный текст по-прежнему дают отказ.
- Сводка различает source fetches (вызовы клиента), попытки повторной обработки
  и успешно восстановленные задания. Сетевые повторы внутри клиента не называются
  одним физическим HTTP-запросом.
- Для повторной обработки receipt получает processing_origin и processed_at_utc.
  Неизвестная первоначальная дата получения не выдумывается; retrieved_at_utc=null.
- Старые планы 1.0.0, их ID и уже завершённые receipts остаются совместимыми.
- Побайтные снимки каталога и пакет защищены от автоматической замены LF на
  CRLF при Git checkout в Windows. Сами исходные байты и их хеши не меняются.

## Применение

Замените `switzerland_climate.py` в папке, из которой запускается загрузчик.
Используйте прежний `plan.json` и прежний каталог результатов:

```bat
python switzerland_climate.py download --plan plan.json --out downloaded
```

586 завершённых jobs проверяются по их хешам и пропускаются. Оставшийся запрос
будет обработан из сохранённого raw при совпадении provider SHA; иначе загрузчик
получит его из сети. Полнота 587/587 у пользователя подтверждается только его
следующей сводкой, а не локальной проверкой одного GRO-файла.

Если отказ повторится, новая строка ошибки даст точное содержимое проблемной
ячейки; оригинал останется сохранённым. Перестраивать каталог или план для этого
обновления не требуется.
