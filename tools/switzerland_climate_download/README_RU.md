# IGE Switzerland Climate Downloader 1.0.0

Получение почасовых станционных наблюдений **MeteoSwiss Open Government Data**,
координат и определений параметров. Python **3.10+**, стандартная библиотека;
`pip install` не требуется. Работает локально отдельно от Streamlit.

Поддерживаются две коллекции FSDI/STAC:

| Сеть в конфигурации | Источник |
|---|---|
| `smn` | Автоматические метеостанции: температура, влажность, давление, ветер, радиация и другие величины |
| `smn-precip` | Автоматические осадкомерные станции: почасовые осадки |

Программа сохраняет частичные ряды. Полный год, полный набор величин или наличие
ручной проверки не являются условиями загрузки. Подготовка доноров, интерполяция,
восстановление пропусков и допуск к EPW выполняются отдельно.

## Что находится в поставке

| Файл | Назначение |
|---|---|
| `switzerland_climate.py` | Каталог, поиск, план, загрузка, экспорт и аудит покрытия |
| `catalog/stations.csv` | Координаты WGS84, высоты станции/барометра, название, сеть, WIGOS |
| `catalog/stations.geojson` | Карта; порядок координат `[longitude, latitude]` |
| `catalog/catalog.json.gz` | Зафиксированный машинный каталог со своим идентификатором |
| `catalog/inventory.csv.gz` | Периоды отдельных параметров по станциям и категориям измерения |
| `catalog/assets.csv.gz` | Почасовые CSV из всех страниц STAC с контрольными суммами поставщика |
| `catalog/parameters.json` | Нативные имена, описания, единицы и типы почасовых параметров |
| `catalog/catalog_manifest.json` | Числа, источники, ETag и SHA-256 |
| `catalog/catalog_warnings.json` | Явные несогласованности между таблицей станций и STAC |
| `catalog/sources/` | Исходные CSV, STAC JSON и официальная документация, gzip без изменения распакованных байтов |
| `config_2016_2025.json` | План десятилетия для обеих сетей |
| `config_smoke.json` | Одни сутки, две метеостанции и одна осадкомерная |
| `config_time_transition.json` | Двое суток на границе 2017/2018 |
| `tests/`, `validation/`, `VALIDATION_RU.md` | Автономные проверки, происхождение образцов и результаты реальной загрузки |

Состав доступных данных определяется этими коллекциями. Этот каталог не
объявляется полным историческим реестром всех когда-либо существовавших станций
Швейцарии. Не включены башенные, ручные суточные и гомогенизированные климатические
коллекции: у них другие измерительные программы и временное разрешение.

## Быстрый запуск

Откройте терминал в распакованной папке. В Windows при необходимости используйте
`py -3` вместо `python`; в Linux/macOS — `python3`.

```bash
python switzerland_climate.py plan --config config_smoke.json --out plan_smoke.json
python switzerland_climate.py download --plan plan_smoke.json --out downloaded
python switzerland_climate.py export --plan plan_smoke.json --out downloaded --station-id BER --year 2025 --plain-csv
python switzerland_climate.py audit --plan plan_smoke.json --out downloaded --report coverage_smoke.csv
```

Выбирается 01.06.2025 для `BER` (Bern/Zollikofen), `SMA` (Zürich/Fluntern) и
осадкомерной `ABE` (Aarberg). Имя `2025.csv` у экспорта этих суток не означает,
что скачан полный 2025 год: отчёт явно содержит границы выбора.

`plan` наблюдения не скачивает. MeteoSwiss предоставляет целые станционные CSV,
часто по десятилетиям. Для выбора одних суток всё равно загружается полный
соответствующий исходный файл, затем выделяется заданный интервал. `historical`
может иметь имя `2020-2029`, хотя фактические наблюдения в нём заканчиваются раньше.
Имя файла не является доказательством покрытия будущих лет.

## Поиск ближайших станций

Температура рядом с Берном:

```bash
python switzerland_climate.py nearest --lat 46.948 --lon 7.447 --date 2025-01-01 --parameters tre200h0 --radius-km 100 --limit 10 --csv nearest_bern.csv
```

Станции осадков из дополнительной сети:

```bash
python switzerland_climate.py nearest --lat 46.948 --lon 7.447 --date 2025-01-01 --networks smn-precip --parameters rre150h0 --csv nearest_rain.csv
```

Для нескольких параметров требуется наличие каждой указанной величины в
инвентаре на заданный момент. Есть фильтры `--elevation-m`,
`--max-height-difference-m`, исключение `--exclude-ids BER` и
`--exclude-wigos <WIGOS_ID>`. Расстояния рассчитываются по гаверсинусу с радиусом
Земли 6371,0088 км. Дата без времени означает 00:00 UTC; можно задать полный
UTC-момент, например `2025-01-01T12:00:00Z`.

Поиск определяет кандидатов по опубликованному инвентарю, а не подтверждает
наличие каждого часового измерения, независимость источников или пригодность
интерполяции. Результат содержит `donor_admission=not_assessed`.

Координаты и высоты в общем справочнике не являются датированной историей
перемещений. `data_since` — начало истории данных, не дата начала действия текущих
координат. Высота барометра сохранена отдельно от высоты станции; пустая высота
не подменяется другой величиной. Для исторических исследований применимость
координат и высоты прибора проверяется отдельно.

Если STAC содержит станцию, которой нет в таблице метаданных, сохраняется его
явная геометрия с отдельным статусом. Название берётся из STAC; высоты, WIGOS и
история не выдумываются. Такая запись отражается в `catalog_warnings.json`.
Без нужного инвентаря параметров она не попадает в датированный поиск доноров;
публикуемые файлы при этом остаются доступными для загрузки.

## Скачать 2016–2025 годы

```bash
python switzerland_climate.py plan --config config_2016_2025.json --out plan.json
python switzerland_climate.py download --plan plan.json --out downloaded
```

Небольшая первая порция:

```bash
python switzerland_climate.py download --plan plan.json --out downloaded --max-jobs 2
```

Повтор той же команды проверяет хеши и пропускает только полностью сохранённые
задания. Учитываются исходный ответ, CSV-часть, метаданные и квитанция. Пропавший
или повреждённый файл требует повторной обработки. Наличие файла без подходящей
квитанции не считается завершением.

STAC предоставляет контрольные суммы `file:checksum` в формате multihash SHA-256;
загрузчик проверяет распакованные исходные байты ответа именно по этой сумме.
Если поставщик пересмотрел файл после создания каталога, программа сообщает
несовпадение и сохраняет отвергнутый ответ отдельно. Нужно обновить каталог,
создать новый план и выбрать новую папку результата. Версии не смешиваются молча.
Если контрольная сумма поставщиком не задана, это явно отражается; собственный
SHA-256 всё равно сохраняется для дальнейшей проверки локальных файлов.

Размер файла в STAC может отсутствовать. В таком случае план показывает `null`,
а не оценку, выдуманную по другой станции. Планирование не выполняет массовые
HEAD-запросы и не начинает загрузку наблюдений ради оценки размера.

Запросы последовательные; интервал по умолчанию 1 с — настройка программы,
не объявленный лимит MeteoSwiss. Временные ошибки повторяются с ограниченным
экспоненциальным ожиданием и случайной добавкой. Учитывается `Retry-After`.
Каталог при обновлении использует ETag/`If-None-Match`, если он опубликован.

Один расчёт защищён `.download.lock`. При обычном Ctrl+C блокировка снимается.
После аварийного завершения удалять её можно только после проверки, что прежний
процесс остановлен. Разные планы имеют отдельные папки результата.

Пример своей конфигурации:

```json
{
  "start": "2024-01-01",
  "end": "2025-12-31",
  "networks": ["smn"],
  "station_ids": ["BER", "SMA"],
  "parameters": ["tre200h0", "ure200h0", "prestah0", "gre000h0"],
  "types": ["historical"],
  "min_interval_seconds": 1.0
}
```

`parameters="all"` выбирает все почасовые параметры соответствующей сети.
Серверный CSV всё равно содержит всю программу измерений станции; исходный
ответ и его нативные столбцы сохраняются целиком. Список параметров определяет
отчётные величины и выбор подходящей сети, но не уменьшает передаваемый CSV.
Отсутствующий в старом CSV столбец отмечается отдельно; измерения не создаются.

Даты без времени включают оба указанных календарных дня. Точный `end` с часовым
поясом является исключающей границей. Например, `end="2025-06-02T00:00:00Z"`
заканчивает выбор перед этим часом. Значения `recent` относятся к текущему году,
`now` — к оперативному окну; они доступны через `types`, но в плане десятилетия
по умолчанию используется только `historical`.

## Основные величины и единицы

| Нативный код | Значение | Единица |
|---|---|---|
| `tre200h0` | Температура на 2 м, средняя за час | °C |
| `tre200hn`, `tre200hx` | Минимум и максимум температуры на 2 м | °C |
| `ure200h0` | Относительная влажность | % |
| `pva200h0` | Парциальное давление водяного пара | hPa |
| `tde200h0` | Точка росы | °C |
| `prestah0` | Давление на высоте барометра, QFE | hPa |
| `pp0qffh0` | Давление, приведённое к морю, QFF | hPa |
| `pp0qnhh0` | Приведение по стандартной атмосфере, QNH | hPa |
| `fkl010h0` | Средняя скалярная скорость ветра | m/s |
| `fu3010h0` | Средняя скалярная скорость ветра, другая единица | km/h |
| `fve010h0`, `dkl010h0` | Векторная скорость и направление ветра | m/s, ° |
| `rre150h0` | Осадки за час | mm |
| `gre000h0`, `ods000h0` | Глобальная и диффузная радиация | W/m² |
| `sre000h0` | Солнечное сияние | min |

Все определения сохранены в `parameters.json`. QFE, QFF и QNH не взаимозаменяются.
Столбцы скорости с разными единицами не усредняются вместе. Температура, влажность,
водяной пар и радиация не рассчитываются заново загрузчиком. В отличие от DWD,
нативная радиация здесь представлена средним потоком W/m²; преобразования между
потоком и энергией или между m/s и km/h не выполняются.

## Время, интервалы, QC и пропуски

Исходный CSV имеет разделитель `;`, кодировку Windows-1252 и время
`dd.mm.yyyy HH:MM` в UTC. Нативный `reference_timestamp` сохраняется. Дополнительно
создаются `timestamp_utc` в ISO-формате и `hour_interval_regime`.

Для агрегатов MeteoSwiss описывает смену правила в 2018 году: прежняя SYNOP-схема
и более позднее объединение шести предшествующих 10-минутных значений относятся
к разным интервалам относительно подписи часа. Поэтому строки до 2018 получают
отдельную метку. Это маркировка опубликованного общего правила; она не заменяет
определение конкретного параметра, например мгновенного значения. Программа не
сдвигает старые ряды на условный час и не пересчитывает интервалы. Сопоставимость
временных операторов для межстрановой интерполяции проверяется отдельно.

В проверенных почасовых CSV **не публикуются индивидуальные QC-флаги**.
Загрузчик сохраняет `qc_status=per_value_flags_not_supplied_in_this_csv` и не
выдаёт эту неопределённость за автоматическую, ручную проверку или ошибочность
измерения. Общее описание процедур поставщика не доказывает статус отдельного часа.

Пропуски представлены пустыми ячейками. Пустой столбец может означать, что величина
на станции не измеряется. Пустоты не заменяются нулями; нулевые значения остаются
значениями. Никакое произвольное число, например `-999`, не вводится как новый
код пропуска. Физический QC и восстановление не применяются. Вычисляемые самим
поставщиком показатели остаются помеченными нативными определениями.

## Экспорт и общая проверка покрытия

```bash
python switzerland_climate.py export --plan plan.json --out downloaded --station-id BER --year 2025 --plain-csv
python switzerland_climate.py export --plan plan.json --out downloaded --station-id ABE --network smn-precip --year 2025 --plain-csv
python switzerland_climate.py audit --plan plan.json --out downloaded --report coverage_2016_2025.csv
```

Без `--plain-csv` экспорт сжат gzip. Команда `audit` работает без сети и без
создания повторных больших экспортов. Она проверяет целостность сохранённых
файлов и формирует таблицу «сеть × станция × год × параметр»:

- ожидаемые часы выбранного периода и отдельно число часов календарного года;
- присутствующие значения и пустые ячейки;
- отсутствующие целочасовые метки, включая часы без строк;
- покрытие до QC и максимальную непрерывную длину разрыва;
- единицы, отсутствие индивидуального QC и сохранение неполных лет.

Процент покрытия относится к выбранному периоду. Для запуска на одни сутки
100% не означает полный календарный год. Отчёты не выдают допуск к EPW или оценку
точности интерполяции. Если обязательные задания ещё не скачаны или повреждены,
экспорт и общий аудит блокируются с явным сообщением.

Если пользователь включил пересекающиеся типы файлов, одинаковые UTC-метки
не суммируются дважды. Приоритет исходных строк: historical → recent → now.
Число пересечений и расхождений сохраняется; конфликт внутри одного типа
блокирует объединение. Нативные значения не смешиваются между версиями одной строки.

## Обновление каталога

```bash
python switzerland_climate.py catalog --out catalog_updated
python switzerland_climate.py plan --catalog catalog_updated/catalog.json.gz --config config_2016_2025.json --out plan_updated.json
```

Без `--catalog` используется поставленный снимок. Переход по всем страницам STAC
обязателен; циклы, дубли и выход за коллекцию приводят к отказу. Исходные версии
ответов сохраняются под SHA-256. Уже созданный план фиксирует задания, контрольные
суммы, станционные параметры и определения величин и не перечитывает их позднее
из обновлённого каталога.

## Структура результата

```text
downloaded/<plan_id>/
  plan.json
  raw/<job_id>/<provider_filename>.csv.gz
  parts/<job_id>.csv.gz
  metadata/<job_id>.json
  receipts/<job_id>.json
  download_summary.json
  errors.jsonl
  rejected/<job_id>/<received_sha256>.csv.gz
  stations/<network>/<station_id>/<year>.csv
  stations/<network>/<station_id>/<year>.coverage.json
```

Имя папки расчёта — первые 20 символов SHA-256 плана. `raw` после распаковки
содержит исходные байты CSV. `parts` — выбранные строки в UTF-8 с нативными полями
и явными временными метаданными. В `metadata` сохранены определения величин,
станционная запись, фактическая кодировка, покрытие и происхождение ответа.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Автономные тесты не используют сеть. Их небольшие CSV — производные фрагменты
реальных ответов MeteoSwiss с сохранением исходных строк. URL, размер и SHA-256
полного исходного файла, преобразование и хеш фрагмента находятся в
`tests/fixtures/provenance.json`. Отрицательные тесты изменяют только копии в памяти.
Реальная загрузка полных исходных файлов проверена отдельно, включая смену
временной схемы на границе 2017/2018; результаты находятся в `validation/`.
