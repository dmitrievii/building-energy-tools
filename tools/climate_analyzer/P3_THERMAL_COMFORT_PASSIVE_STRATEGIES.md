## P3 natural-ventilation UX refinement
The separate T×humidity-ratio sensitivity view is removed at the user's request; Psychrometric NV overlay remains its canonical view. Temperature–wind suitability is a dedicated option only with wind data, sequential white–green scale, gray missing cells and configured threshold boundary lines. Fixed-width bins retain gaps. Continuous ventilation periods replaces the former daily line chart with monthly counts of observed days with/without at least the user-specified uninterrupted suitable interval; nightly persistence uses the analogous night counts. Detailed per-day values remain expandable/exportable. Partial observed days are not claimed complete. Navigation refresh guard handles warm processes retaining the older navigation contract; full runtime deployment still needs verification/restart when fingerprints differ.
