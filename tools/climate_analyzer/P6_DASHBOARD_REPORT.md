# P6 dashboard and report implementation candidate

Overview offers Climate summary (default, retained), Annual climate dashboard, Building design dashboard (hourly inputs only). Select one actual year from a multiyear selection and retain global filter. Monthly source dashboard restricts itself to published monthly values; no subdaily design reconstruction. KPI totals are selected-period, not annualized. Dashboard consumes shared directional wind classes, isotropic POA, degree metric, P4 complete-day and P3 UTCI/ventilation load engines. Night flushing uses full source day history where supplied, and known nighttime intervals only. Optional UTCI has uniform MRT=T and explicit wind multiplier, not a qualified radiant model. No PET until independent MRT and PET validation.

Report adds one navigation page, session-local immutable Plotly snapshots after global presentation/underlay settings. Captures chart-level interpretation where render_plot supplies it; other direct charts may lack separate interpretation. Source, selected timestamps, filter, context and optional manual notes retained across source changes. Reorder/remove, A4/A3 landscape/portrait, printable self-contained HTML, server PDF via Plotly static rendering (Kaleido) and ReportLab; fails closed if static rendering fails, local HTML print fallback. Captures actual figure data/layout, not browser zoom/rotations or unrecorded widget inputs. No report content is sent to external services. Limit 24 charts and 25 MiB figure JSON per session. Independent chart/export/browser/PDF and scientific qualification remains pending.

Source-neutral comparison snapshots explicitly record each compared dataset, its transformed period, records, reference and comparison-specific filters. Dashboard year is chronological regardless of the global profile presentation setting. Keyed chart controls are captured selectively; unkeyed local widgets and browser interactions are not asserted to be serialized. Direct charts without an interpretation use manual report notes.
