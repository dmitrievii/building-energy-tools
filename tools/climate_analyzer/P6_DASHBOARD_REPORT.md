# P6 dashboard and report implementation candidate

Overview offers Climate summary (default, retained), Annual climate dashboard, Building design dashboard (hourly inputs only). Select one actual year from a multiyear selection and retain global filter. Monthly source dashboard restricts itself to published monthly values; no subdaily design reconstruction. KPI totals are selected-period, not annualized. Dashboard consumes shared directional wind classes, isotropic POA, degree metric, P4 complete-day and P3 UTCI/ventilation load engines. Night flushing uses full source day history where supplied, and known nighttime intervals only. Optional UTCI has uniform MRT=T and explicit wind multiplier, not a qualified radiant model. No PET until independent MRT and PET validation.

Report adds one navigation page, session-local immutable Plotly snapshots after global presentation/underlay settings. Captures chart-level interpretation where render_plot supplies it; other direct charts may lack separate interpretation. Source, selected timestamps, filter, context and optional manual notes retained across source changes. Reorder/remove, A4/A3 landscape/portrait, printable self-contained HTML, server PDF via Plotly static rendering (Kaleido) and ReportLab; fails closed if static rendering fails, local HTML print fallback. Captures actual figure data/layout, not browser zoom/rotations or unrecorded widget inputs. No report content is sent to external services. Limit 24 charts and 25 MiB figure JSON per session. Independent chart/export/browser/PDF and scientific qualification remains pending.

Source-neutral comparison snapshots explicitly record each compared dataset, its transformed period, records, reference and comparison-specific filters. Dashboard year is chronological regardless of the global profile presentation setting. Keyed chart controls are captured selectively; unkeyed local widgets and browser interactions are not asserted to be serialized. Direct charts without an interpretation use manual report notes.

## P6 HF1 — report capture rerun fix
The original capture button inherited the continuously incrementing Plotly widget key, so Streamlit could not deliver the click on a rerun. Capture now uses page plus deterministic rendering ordinal and a callback with the displayed figure/context as arguments. The callback persists the snapshot before rerender; the page and sidebar show actual basket size. AppTest covers capture, duplicate suppression, changed chart, navigation to Report and return. Report storage remains session-local.

## P6 HF2 — chapter-based professional report
Report opens with source/location and selected-period climate statistics, a geographic locator using bundled Natural Earth 1:110m public-domain country boundaries (not street imagery), and chapter names. Chapter opening pages contain captured source-specific descriptive statistics, not combined incompatible datasets. PDF and HTML use 11 pt body and projected physical 11 pt graph-label sizing; report headings use larger type. Printed charts omit raw diagnostic payloads, with concise scope only where needed; complete technical metadata is optionally downloaded separately. 20 standard charts, built-in presets (Climate overview, Architectural climate study, Passive design, HVAC & engineering, All standard diagrams), session-local custom presets, select all saved diagrams, and bulk capture of all displayed Plotly diagrams. Standard charts use existing scientific kernels and declared reference configurations. Do not generate combinatorial parameter variants. Capacity raised to 80 diagrams / 65 MiB; older captures without verified fingerprints must be re-added for station/statistics metadata. Source filters and identity retained; missing source capabilities omitted. Pending browser/PDF layout and catalogue validation. 

## Calendar heatmap axis correction
All shared Plotly presentation and report paths explicitly label represented calendar months. Annual date and calendar-position heatmaps show Jan–Dec (or the selected span), with compact month labels and rotated tick text if needed; longer spans use bounded ticks including the final month. The chronological matrix retains missing selected calendar slots as NaN. UTCI grids no longer truncate multiyear selections to the first year. Numeric non-calendar heatmaps retain their physical axes. Labels do not imply missing December observations were reconstructed.
