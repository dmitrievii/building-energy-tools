- S-01–S-03: 2D and technical sun paths, temperature and threshold-based cold/intermediate/hot classifications; optional rectangular aperture direct-shadow mask. - S-04: monthly unshaded POA, shaded direct-only POA and intercepted direct. Diffuse and ground components explicitly remain unchanged, so this is not a full optical shading model. Active albedo and shared POA kernel retained.
- S-05–S-07: 145/577-patch 2D/3D sky distribution with thermal filters. Direct beam placed in its containing sky patch using actual solar cosine; diffuse normalized by exact patch projected solid angle. Values are contributions to horizontal irradiation in kWh/m² per patch, not radiance or POA. Common coincident valid daylight inputs per quantity, no ground patch. Isotropic DHI may operate without DNI; direct and total require admitted DNI. Perez (1993) research option uses published coefficients, daylight irradiance from interval energy / physical duration, relative airmass and extraterrestrial radiation. Nonnegative relative radiance and exact horizontal normalization are enforced. Brightness bounds 0.01–0.6, with intermediate clearness correction 0.2. Coefficients verified against Radiance reference table; independent numerical Radiance comparison and low-sun sensitivity qualification pending. These are not claimed to be identical to IVANCALC.
- S-08–S-09: admitted POA components in existing variable explorer, duration and heatmap use canonical extensive quantity definitions.
- S-10: orientation–tilt sensitivity lines in existing heatmap analysis; missing input periods not substituted by zero.
- S-11: valid interval DHI/GHI percentage, GHI > 0, 0 ≤ DHI ≤ GHI. No clipping or inference; mean interval ratio differs from ratio of totals.
- GP-09: optional PNG/JPEG/WebP plan image from current session; image offset, scale, rotation, opacity relative to compass polar domain; restrict to 2D directional polars; no geographic registration or 3D texture; no external upload service. UI/PNG/SVG qualification required.

## P2 analytical direct-beam shading
The spatial sampling parameter is removed. Let n > 0 be the outward solar direction cosine, a = |lateral|, b = vertical > 0, W and H the opening dimensions, D the overhang depth, and F the illuminated-side fin depth (opposite fin contributes zero). For the upward and sunward-side ray exits, define t* = min(H/b, W/a), with W/a = infinity when a = 0. Then t_o = min(t*, D/n) and t_f = min(t*, F/n). Exact clipped areas are A_o = b t_o (W - a t_o/2), A_f = a t_f (H - b t_f/2). Their interiors are disjoint because a ray exits the rectangular aperture footprint through either the top or the sunward side first, never both; the common corner ray has zero area. F_sh = (A_o + A_f)/(W H). The implementation evaluates the equivalent normalized formula, with the original grazing cutoff n > 1e-10 and missing/invalid directions preserved. No polygon iteration or spatial grid at runtime. Independent projected-polygon clipping oracle, known analytical cases, symmetry, monotonicity, missing states, full shading, zero depth and energy closure are covered by tests. The sun-path mask retains an angular visualization grid but every point is evaluated analytically. Direct-only scope, existing hourly sun position, geometry and POA model unchanged. No measured speedup is claimed until benchmarked.

## P2 seasonal and hourly shading
Design — Shading analysis adds a monthly stacked calendar rose and a month–hour heat map. The analytic first-hit regions now retain overhang, left-fin and right-fin contributions; their sum equals the existing total shadow fraction. The energy metric sums intercepted interval Wh/m² and converts to kWh/m²; the reduction metric divides summed intercepted energy by summed unshaded direct POA energy; the geometry-only area metric averages first-hit fractions over front-facing daylight duration. Each group uses a common denominator, retains missing/undefined cells, and follows the active analysis clock and Data filter. Multi-year views explicitly select one year rather than pooling unlike years. Calendar rose angle is month, not azimuth. No diffuse/ground shading or intra-interval integration is added.
