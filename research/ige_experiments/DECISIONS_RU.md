# IGE — журнал решений по экспериментам

Дата: 2026-11-07. Связь: `program_v1.json`, версия 1.0.

| ID | Решение | Основание и последствия |
|---|---|---|
| D01 | Сохранить E0–E8 | Нумерация уже есть в научной главе 2026-11-05; новая программа развивает её, не объявляет прежнюю работу потерянной |
| D02 | Три самостоятельные линии | Пространственная интерполяция, суточная обратная задача и сценарный климат имеют разные входы и критерии истины |
| D03 | Использовать доступные часы неполных рядов | Прямое решение пользователя; годовой H1/S1 gate не применим к новой почасовой исследовательской выборке; нужен отдельный адаптер |
| D04 | Автоматический QC не равен браку | Прямое решение пользователя; manual/automatic входят в основной анализ, категории и QC контроля/доноров раздельны; явный provider reject сохраняет свой смысл |
| D05 | Не выдумывать QC | DWD QN и GeoSphere q21 имеют собственную семантику; MeteoSwiss без опубликованного per-value QC остаётся not_supplied |
| D06 | Сравнивать точность вместе с покрытием | Общие часы дают парную ошибку; собственное покрытие и полный знаменатель показывают цену отказов/масок |
| D07 | Учесть операторы и высоты | UTC недостаточно; интервал, агрегат, фаза RH, земля/термометр/барометр/анемометр/модельная орография различаются |
| D08 | Сохранить отрицательные результаты | R1/terrain/B4/P2 не становятся победителями из-за наличия нового каталога; численная сходимость C2 не доказывает точность погоды |
| D09 | Сохранить IV1 и его SOURCE_BLOCKED | Утраченный metadata body нельзя заменить новым ответом с прежним SHA; изменение источника получает новую acquisition/version и явную регистрацию |
| D10 | Не обещать слепоту уже скачанных лет | Acquisition, просмотр raw, fit и просмотр ошибок регистрируются отдельно; старые правила раскрытия контейнеров не переписываются |
| D11 | Последовательные волны, параллельные независимые jobs | Выбор модели зависит от предыдущих результатов; фиксированные страны/targets/периоды/варианты считаются параллельно без изменения общего fit |
| D12 | Не ждать всех стран для E0/E1.0 | Достаточен ограниченный фиксированный D-снимок; готовность данных каждой ветви проверяется отдельно |
| D13 | Сначала дешёвые контроли, затем совместные варианты | NN/IDW и frozen replay отделяют пользу нового метода; ограниченная T×p×moisture матрица проверяет взаимодействия без полного перебора |
| D14 | Разделить одинаковые и более богатые входы | I0/I1/I2/ID позволяют не приписывать преимущество нативной колонки только алгоритму |
| D15 | E4.M можно вести параллельно на фиксированной базе | Новый пространственный метод не должен менять входы месячного F1 посреди опыта; E4.D/IV1 сохраняют свои source gates |
| D16 | E6 не зависит от выбора нового spatial winner | Его frozen-ветвь может работать после E1.0; рекомендуемая волна 2 отражает ресурсный порядок |
| D17 | Физическая допустимость, численная корректность, точность и эксплуатация — четыре оси | CI PASS, малый residual и форматный EPW не являются независимой станционной квалификацией |
| D18 | Новый C открывается после запечатывания | Станции, периоды, параметры, contrasts, margins, статистика, бюджеты и ожидаемые jobs фиксируются заранее; пока они TBD, полная пререгистрация не заявляется |
| D19 | Не менять рабочие ограничения gap recovery | 2 ч и 1% остаются текущим ограниченным режимом; 6/24/61 ч — отдельные исследовательские arms |
| D20 | E7 требует реальную модель здания и движок | Файл EPW и градусо-часы не заменяют энергетическую симуляцию; отсутствие входов блокирует только соответствующую ветвь |
| D21 | Не запускать научные расчёты этим документом | Текущий запрос — структурировать и документировать; следующий вычислительный пакет E0+E1.0 требует конкретных файлов пользователя/готового D-снимка |
| D22 | Критически переоценить старые коэффициенты | Дополнение v1.1 по прямому решению пользователя: старые коэффициенты — исторические контроли, без обязательного default или центра регуляризации |
| D23 | Оценивать непрерывные параметры автоматически | Линейный блок — регрессия; веса/профили — соответствующая непрерывная оптимизация; полная ручная сетка не является основным оценивателем |

| D25 | Большой массив не заменяет независимую проверку | Проверяются rank, географическое смешение, зависимость часов, состав старого обучения и переносимость; контрольная площадка исключается из нового fit во всех периодах |

## Открытые пункты

- Доступные пользователю полные/частичные файлы и их фактические хеши: локальные
  AT/DE/CH данные не считаются проверенными в этой среде по одному сообщению.
- Точные D/V/C списки и журнал прежнего раскрытия; кандидаты 2026 не объявлены blind.
- Новые margins, первичные contrasts, длины блоков и multiplicity: выбрать до C.
- Допуски времени/RSS/сетевого объёма и число workers: определить E1.0.
- Проверенные исторические высоты приборов, допустимость временных операторов,
  длинные климатические окна, независимая радиация/LW, native future pressure.
- Готовность исследовательских hourly adapters; C1/P3/C3/J1 не объявлены готовыми.
- Источники для IV1 и модель/движок E7: отдельные SOURCE_BLOCKED при отсутствии.

Документ не изменяет main, алгоритмы приложения или прежние численные выводы.
Изменение плана после раскрытия C требует новой версии и объяснения, какое
утверждение осталось подтверждающим, а какое стало исследовательским.
