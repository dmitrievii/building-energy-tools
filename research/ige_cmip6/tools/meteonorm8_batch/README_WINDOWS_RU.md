# IGE P8 — пакетная генерация Meteonorm 8 на Windows

## P8.0.4 — исправление отказа Batch Locations Import (Meteonorm 8.2)

**Важно: предыдущий совет импортировать \`locations_format22.csv\` (запятые + необязательное \`situation\`) был неподтверждён и мог вызвать \`0 valid locations imported\`.**

Официальное руководство Meteonorm 8.2, §2.4.1.3, показывает пример импорта с **TAB-separated** колонками \`name\`, \`longitude\`, \`latitude\`, \`altitude\`, без \`situation\`. Новый генератор использует его как основной вариант. Подготовлены простые **ASCII + CRLF** файлы:

- \`mn8_project/batch_input/pilot_one_graz_tabs.txt\`: сначала одна точка Graz; использовать команду **Locations > Import locations for batch mode**, а не *Import user defined locations*.
- \`mn8_project/batch_input/locations_5_tabs.txt\`: если одна точка принята, расширить до пяти.
- \`mn8_project/batch_input/locations_5_semicolon.csv\`: диагностический fallback, если этот Meteonorm отвергает TAB.
- Совместимые имена \`locations_format22.tsv\` и \`locations_format22.csv\` теперь перегенерируются с исправленным макетом.

**Порядок:** запустить \`01_prepare_batches.bat\` заново (он НЕ перезаписывает изменённый \`project_config.json\`; новые файлы batch_input перегенерируются), затем импортировать \`pilot_one_graz_tabs.txt\`. Если появится \`1 valid location imported\`, перейти к \`locations_5_tabs.txt\`, проверить все пять названий, только потом запускать \`05_guarded_pilot.bat\` в \`inspect\`.

Если даже одна точка не импортируется, остановиться. Прислать **скриншот открытого меню Locations с выбранной командой** и сообщение импорта. Не следует перебирать ещё 60 экспортов или включать \`save\`. Метод пока не подтверждён реальным запуском на пользовательском Windows.

Официальный источник: https://mn8.meteonorm.com/assets/downloads/mn82_software.pdf, §2.4.1.3.


## P8.0.3 — первый управляемый пилот (4 загруженных UIA отчёта)

Диагностика установленного **Meteonorm v8.2.0** подтверждает:
- Период: \`PeriodContemporary\`, \`PeriodFuture\`; RCP — RadioButton по точному имени внутри \`Scenario for future periods\`;
- год: \`futureTimePeriod\` (значения 2020–2100);
- случайное зерно: \`randomSeedBox\`, только внутри Advanced settings;
- EnergyPlus EPW: \`outputFormat_22\`; Save All: \`SaveAllResultsButton\`.

**Безопасный пилот, без полной автоматизации 60 файлов:**

1. Выполни \`01_prepare_batches.bat\` (если не запускал). В Meteonorm через Locations импортируй \`mn8_project/batch_input/locations_format22.csv\` и выбери **все пять** IGE-локаций. Если импорт ещё не работает, экспорт пока не запускать; убедись, что UI показывает ровно 5 выбранных.
2. На странице **Calculation settings** (Data) раскрой **Advanced settings** и оставь Meteonorm открытым.
3. Запусти \`05_guarded_pilot.bat\` и введи режим **inspect**. Это чтение UIA без изменений, результат \`mn8_project/uia_pilot_v03.json\`.
4. Только после подтверждения правильного списка локаций: снова запускай \`05_guarded_pilot.bat\` с режимом **configure**, сценарием \`rcp45_2050\` и seed \`1\`. Сценарий и переключения проверяются чтением состояний UIA.
5. Когда \`configure\` успешно подтверждён: режим **prepare** дополнительно выберет \`EnergyPlus (.epw)\` и перейдёт к Output, но НЕ будет сохранять файлы.
6. Режим **save** отдельно вызывает \`Save all results to disk\`, требует ввода \`YES\` и строго проверяет имена пяти IGE-станций по \`project_config.json\`. Первое окно сохранения необходимо проверить вручную. Не запускай save до подтверждения предыдущих этапов.
7. Пришли \`mn8_project/uia_pilot_v03.json\`, **даже если появился отказ**: в нём есть причина и место отказа. Не отправляй лицензии или ключи.

Текущая версия не утверждает, что Windows UIA паттерны на реальном ПК уже успешно вызваны: они подтверждены только с помощью снимков и Linux CI на искусственных объектах. Это осознанный пилот с отказом по умолчанию. Полная автоматизация 12×5 EPW последует только после реального проверки выбора, пакетного импорта и поведения диалога сохранения. **Не запускать весь план без квалификации одного пакета.**


## Уточнение P8.0.2 — глубокая диагностика WPF UIA

Три оригинальных снимка main/future/advanced (Meteonorm 8.2.0) успешны, но диагностическая глубина 5 показывает только \`Period\`, \`Scenario for future periods\`, \`First random seed\`, а не вложенные кнопки и ComboBox. Добавлен \`02b_inspect_controls_deep.bat\` для чтения ТОЛЬКО \`DataExpander\`, \`FormatExpander\` и \`OutputExpander\` до глубины 7 внутри панели.

1. Откройте страницу Future в Meteonorm; запустите \`02b_inspect_controls_deep.bat\`, введите \`future\`.
2. Раскройте Advanced settings; повторите с \`advanced\`.
3. Перейдите на страницу Output format; повторите с \`format\`.
4. Перейдите на страницу Output/Save; повторите с \`output\`.
5. Отправьте четыре \`mn8_project/ui_deep_*.json\`.

Скрипт не кликает элементы, не меняет выбранные параметры, не читает содержимое редактируемых/парольных полей и не обходит страницы активации/локаций. Для этого шага не требуется повторно выполнять \`01_prepare_batches.bat\`, а исходные файлы \`ui_main.json\`, \`ui_future.json\`, \`ui_advanced.json\` не нужно удалять. Пока не подтверждено, что все нужные ComboBox доступны UIA, полная безручная генерация 60 EPW не обещается.


## Текущий статус

Версия 0.1: подготовка пакетного импорта, план 12 расчётных запусков, структурный контроль экспортов EPW, диагностика Windows UI Automation. **Переключение сценариев RCP, годов и seed пока выполняется в приложении**, так как оно не описано как параметр пакетного CSV. Автоматизация этих переключений будет реализована после проверки элементов интерфейса твоей установленной версии. Не используем слепые клики с фиксированными координатами.

Работа не требует переноса лицензии Meteonorm и не включает установщик, активацию или коммерческие климатические данные. Коммерческие файлы EPW остаются на локальном компьютере.

## Что сделать

**Шаг 1.** Распакуй этот ZIP в отдельную папку Windows (например, C:\IGE\MN8_Batch). Нужен Python 3.9+ с командой py -3.

**Шаг 2.** Запусти файл 01_prepare_batches.bat. Он создаст папку mn8_project с:
- project_config.json — пять географических точек, высоты, situations, четыре климатических варианта, три seeds;
- batch_input/locations_format22.csv и .tsv — импорт координат в Meteonorm 8;
- run_plan.csv — 12 комбинаций настроек;
- exports/<run_id>/ — папки для пакетных экспортов.

Перед полноценным опытом уточни значения высоты и идентичность выбранной метеостанции в project_config.json; для Wien и Innsbruck координаты исходно заданы как пилотные, а не как верифицированные GeoSphere station IDs.

**Шаг 3.** Открой Meteonorm 8 → Locations → Import locations for batch mode. Импортируй batch_input/locations_format22.csv. Если Windows некорректно интерпретирует разделитель CSV — попробуй вариант TSV. Оба варианта содержат три служебные строки, предписанные руководством Meteonorm 8.2: Formattyp = 22; Save = hour; список колонок (name,longitude,latitude,altitude,situation).

**Важно:** сначала проверь на одном EPW, что пакетный импорт принят твоей версией. Затем переключай в Meteonorm категории Contemporary/Future, RCP4.5/RCP8.5, целевой год 2050/2100 и First random seed. Сохраняй все пять EPW одним Save All в папку из соответствующей строки run_plan.csv. Всего планируется 12 пакетных расчётов × 5 точек = **60 EPW**. Это промежуточное решение, пока не получено дерево элементов интерфейса.

**Шаг 4.** Дважды щёлкни 03_verify_exports.bat. Скрипт проверяет наличие всех ожидаемых файлов, координаты каждой точки, 8760 почасовых записей, 35 EPW-колонок, основные физические диапазоны, SHA-256 и дубли между seeds. Создаётся mn8_project/verification_report.json. Скрипт не меняет исходные EPW.

**Шаг 5.** Для перехода к полностью автоматическому режиму, пока Meteonorm открыт:
- установи однократно: py -3 -m pip install --user pywinauto comtypes pywin32;
- запусти 02_inspect_meteonorm_ui.bat отдельно для основного окна, страницы Future scenario и Advanced settings;
- пришли три файла mn8_project/ui_*.json.

Скрипт читает названия/AutomationId элементов, **не кликает**, а содержимое текстовых полей Edit намеренно не записывает. По этим данным можно безопасно автоматизировать конкретную версию GUI с контролем того, что выбраны правильные RCP/год/seed.

### Дополнительно: состав установочного ZIP

Чтобы без запуска и распаковки проверить структуру присланного установщика, запусти 04_inventory_installer_zip.bat. Укажи путь к исходному файлу Meteonorm 8(1).zip и пришли полученный meteonorm8_installer_inventory.json. Файлы активации, серийные номера и лицензионные ключи присылать не надо.

## Правила научного сравнения

- RCP4.5 ≠ SSP245 строго по постановке сценария; RCP8.5 ≠ SSP585 строго.
- Исходный Contemporary, UHI, модель рассеянной радиации, горизонт, высота, часовой пояс и seed должны быть зарегистрированы.
- Три seeds дают оценку стохастической изменчивости Meteonorm, но не неопределённость разных GCM.
- Структурный PASS EPW не равен валидации климата. Независимый эталон исторического климата — наблюдения GeoSphere, а не Meteonorm.
